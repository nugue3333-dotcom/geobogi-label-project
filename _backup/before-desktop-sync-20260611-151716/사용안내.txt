라벨 출력 관리 프로그램 사용안내

1. 처음 설치한 PC에서 00_install_trusted_location.cmd를 1회 실행하세요.

2. 프린터설정.exe를 실행해서 고객 프린터에 맞게 설정하세요.
   - 연결 방식: LAN 또는 USB
   - 프린터 브랜드: BIXOLON, TSC, Zebra
   - 용지 크기, 인쇄 방식: 감열 또는 열전사
   - 바코드 종류, X, Y 좌표

3. 라벨출력관리.exe를 실행하세요.
   - 출력 목록 탭: 실제 출력할 라벨 데이터를 편집합니다.
   - 바코드 DB 탭: 스캔한 바코드로 조회할 품목 DB를 편집합니다.
   - 상단 스캔창에서 바코드를 스캔하고 Enter를 누르면 바코드 DB 탭으로 이동해서 해당 상품 행을 선택합니다.
   - 상품 확인용 조회 기능이므로, 출력 목록에 자동 입력되지는 않습니다.
   - 출력 목록에 적용하려면 출력 목록 탭의 barcode 셀에 바코드를 스캔하거나 직접 입력하세요.
   - DB에 없는 바코드면 "DB에 없는 바코드 입니다." 팝업이 표시됩니다.

4. 저장 버튼을 누르면 print_queue.xlsx와 barcode_db.xlsx에 저장됩니다.

5. 출력 파일 확인 버튼을 누르면 실제 프린터로 보내지 않고 출력 명령 파일만 생성합니다.

6. 라벨 출력 버튼을 누르면 현재 설정된 프린터로 바로 출력합니다.

7. 출력 결과나 오류 내용은 04_open_last_log.cmd로 확인할 수 있습니다.

주의사항
- 라벨출력관리.exe, print_labels.exe, 프린터설정.exe, config.ini 파일 이름은 변경하지 마세요.
- barcode, item_code, lot_no는 숫자로 시작해도 문자로 관리하는 것을 권장합니다.
- print_qty 값이 실제 출력 매수입니다. 비어 있으면 기본 1장으로 처리됩니다.
- 엑셀을 직접 열 필요는 없지만, 백업이나 대량 수정이 필요할 때는 print_queue.xlsx와 barcode_db.xlsx를 열어 확인할 수 있습니다.
