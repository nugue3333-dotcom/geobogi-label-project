거복이의꿈 바코드 프린터·스캐너 패키지 판매 랜딩페이지 구성안입니다.

**1. 히어로 섹션**
- 메인 카피: 사업장에 꼭 맞는 바코드 프린터 + 스캐너 패키지를 한번에
- 부가 카피: 설치부터 출하까지, 라벨 발행의 모든 것을 해결합니다
- CTA: 지금 패키지 구성 보기 / 문의하기

**2. 문제 제기 (Pain Point)**
- 바코드 프린터 고장으로 출하 지연되는 경험
- 스캐너 인식 오류로 재고 관리가 혼란스러운 경우
- 장비별 개별 구매로 호환성 문제가 발생하는 경우
- 라벨 발행 프로그램 사용법을 몰라 업무 효율이 떨어지는 경우

**3. 솔루션 개요**
- 프린터 + 스캐너 + 프로그램을 검증된 패키지로 제공
- 설치·교육·AS까지 원스톱 지원
- 소규모 사업장부터 중소물류 창고까지 커버

**4. 패키지 구성 / 가격**
- 베이직 패키지: 프린터 + 스캐너 + 기본 프로그램
- 스탠다드 패키지: + 여분 소모품(라벨, 리본) + 3개월 무상 AS
- 프리미엄 패키지: + 1년 전용 교육 + 우선 출동AS + 업종 맞춤 설정
- 각 패키지에 포함 장비 모델명, 규격(해상도, 인식속도), 라벨 사이즈 지원 범위 명시

**5. 제품 특징**
- 프린터: 열전사/직열 방식 선택 가능, 203/300 DPI, 다양한 라벨 폭 지원
- 스캐너: 1D/2D 모두 인식, 유선/무선 옵션, 충전식 배터리 내구성
- 호환성: 주요 바코드 포맷 지원, Windows 기반 라벨 프로그램 연동
- 연결: USB/시리얼/블루투스/와이파이 옵션

**6. 사용 방법 / 적용 사례**
- 스텝1: 패키지 수령 후 설치
- 스텝2: 라벨 프로그램으로 바코드 디자인
- 스텝3: 프린터로 라벨 출력 → 제품 부착
- 스텝4: 스캐너로 입출고 관리
- 적용 업종: 소매점, 물류창고, 제조현장, 식품유통, 병의원/약국

**7. 차별점 / 왜 우리인가**
- 실제 거복이의꿈 프로그램(라벨 발행)과 완전 연동
- 장비와 프로그램을 한 공급처에서 제공해 문제 발생 시 원인 파악이 빠름
- AS 및 소모품 공급이 안정적
- 업종별 라벨 템플릿 기본 제공

**8. 고객 후기 / 신뢰 요소**
- 실제 사용 후기 (짧은 인용 + 이름/업종)
