## 히어로 이미지 기준

- 스캐너, 라벨 발행 프로그램 화면, 라벨 프린터가 한 흐름으로 보이게 구성합니다.
- 브랜드 로고, 모델명, 가격, 가짜로 읽을 수 있는 UI 텍스트를 넣지 않습니다.
- 특정 프린터/스캐너 모델처럼 보이는 외형은 피합니다.
- 이미지 캡션은 구성 예시이며 실제 모델과 지원 범위는 상담 후 확정된다고 적습니다.
