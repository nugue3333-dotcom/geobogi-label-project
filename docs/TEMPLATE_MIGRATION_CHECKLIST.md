# 고객 도안 이전 대조표

이 문서는 접수·검수 양식이며 실제 이전 완료 기록이 아닙니다. 고객 원본·실제 데이터는 Git에 올리지 않습니다. 업무 식별번호와 비식별 예제, 보안 저장소의 증거 참조만 기록합니다.

## 전환 승인

- 미지원 항목·수동 작업·주의사항: 작성 대기
- 비교 샘플 수와 종류(일반 / GS1 / 그림 포함): 작성 대기
- 소프트웨어 검증: 미실행
- 물리 출력·스캔 검증: 미실행
- 고객 확인 / 담당자 확인 / 승인 날짜: 승인 대기

명령 생성 또는 프린터 전송은 실제 라벨 성공 판정과 다릅니다. 도안 3건 이상을 검토하려는 계획과 실제 검토 완료 수를 구분하여 기록합니다.
