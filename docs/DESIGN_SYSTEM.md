# 거복이의꿈 디자인 시스템

## 기준

- Stitch project: `17945981263713317390`
- Stitch design system: `assets/18101280918705604467`
- Name: `Geobogi Barcode Ops Soft B2B`

## 톤

거복이의꿈은 바코드 프린터, 스캐너, 라벨 발행 프로그램, 설치지원 범위를 업무 환경에 맞춰 상담하는 패키지 브랜드입니다. 장비만 파는 느낌보다, 출력 업무 흐름을 같이 정리해 주는 실무형 B2B 서비스처럼 보여야 합니다.

## 색상

| 역할 | 값 | 사용처 |
|---|---:|---|
| Ink | `#122033` | 본문, 프로그램 기본 텍스트 |
| Navy | `#0f2742` | 브랜드, 제목, 선택 상태 |
| Blue | `#2563eb` | 주요 CTA, 소프트웨어 액션 |
| Green | `#1f7a5a` | 확인됨, 준비됨, 미리보기 기준 |
| Amber | `#b86b18` | 상담 필요, 확정 전 항목 |
| Surface | `#f6f8fb` | 페이지와 앱 배경 |
| Surface Blue | `#eef4ff` | 헤더, 패널, 선택 탭 |
| Border | `#dbe4ef` | 카드, 표, 입력창 경계 |

## 형태

- 버튼, 입력창, 카드, 패널은 `4px`에서 `8px` 사이의 낮은 radius를 사용합니다.
- 카드 안에 카드를 중첩하지 않습니다.
- 홈페이지는 여백을 넉넉하게 쓰고, 프로그램은 표와 설정 패널이 잘 보이도록 더 조밀하게 배치합니다.

## 카피 가드레일

아래 표현은 사용하지 않습니다.

- 최저가
- 당일 설치
- 무제한 지원
- 모든 프린터/스캐너 호환
- 오류 없음
- ERP/POS/쇼핑몰 연동 보장
- 확정되지 않은 가격, 보증, 환불, 배송 조건

모델, 라벨 규격, 설치지원, 보증, 환불, 배송, 외부 연동은 `상담 및 문서 확인 후 확정`으로 표현합니다.
