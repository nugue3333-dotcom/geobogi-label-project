# 고객 배포 방법

## 최신 배포 · 2026.10.13.05

[GitHub Releases의 고객용 전체 ZIP](https://github.com/nugue3333-dotcom/geobogi-label-project/releases/tag/v2026.10.13.05)을 다운로드합니다. GitHub의 소스 ZIP은 고객 실행 패키지가 아닙니다.

1. `채움랩_라벨출력_고객용_20261013_05.zip`을 새 폴더에 모두 풉니다.
2. `처음실행_점검.cmd`로 필수 파일과 설정을 점검합니다.
3. `프린터설정.exe`에서 장비·연결·라벨 크기를 확인합니다.
4. `시작하기.cmd`로 라벨 출력 관리를 실행합니다.
5. 기존 고객 데이터는 백업한 뒤 [업데이트·복구 안내](UPDATE_AND_RECOVERY.md)에 따라 이전합니다.

## 필수 구성

- `고객환경점검.exe`, `라벨디자이너.exe`, `라벨작업실행기.exe`, `라벨출력관리.exe`, `라벨출력엔진.exe`, `프린터설정.exe`
- 시작·점검·백업·복구 스크립트, 기본 설정과 예제 DB, 템플릿
- 고객 PDF·Word·텍스트 매뉴얼, 로고·아이콘·글꼴
- `tools/ocr` 런타임, 바코드 엔진과 대응 소스·라이선스, 배포 파일 명세

보조 파일이 필요하므로 EXE만 따로 전달하지 않습니다. 전체 ZIP의 SHA256은 [릴리스 안내](RELEASE_2026.10.13.05.md) 및 Releases의 `SHA256SUMS.txt`에서 확인합니다.

## 개발자 배포 절차

개발은 `개발소스`에서 진행합니다. 실제 테스트 결과와 6개 실행파일의 빌드·동기화·파일 명세 검증을 완료한 뒤 배포본을 생성합니다. 실행 명령과 필수 검증은 [개발소스 릴리스 체크리스트](../개발소스/docs/RELEASE_CHECKLIST.md)를 따릅니다.

고객 설정·실제 DB·로그·백업·지원 ZIP·개발 캐시를 공개 소스에 올리지 않습니다. 고객에게 전달할 패키지에는 검토한 예제 데이터만 넣습니다. 실제 인쇄·스캐너 판독과 계약 조건은 자동 검증과 별도로 확인합니다.
