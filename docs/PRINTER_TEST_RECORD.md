# 프린터 출력 검증 기록

코드 테스트(49 passed)는 완료됐으나 실물 프린터 출력 검증은 이 문서로 관리한다.

- 테스트일: 2026-09-29

## 1. 테스트 절차 (기종 공통)

1. 프린터 전원을 켜고 USB로 PC에 연결한다.
2. 제조사 드라이버를 설치한다. (BIXOLON: 공식 드라이버)
3. `라벨디자이너.exe`를 실행한다.
4. 아래 기종별 표의 항목을 순서대로 출력한다.
5. 출력된 바코드를 스캐너로 스캔해서 데이터가 일치하는지 확인한다.
6. 엑셀 연동 항목은 10행짜리 테스트 엑셀로 연속 출력한다.
7. 결과를 아래 표에 기록한다. (통과 / 실패 / 미실시)
