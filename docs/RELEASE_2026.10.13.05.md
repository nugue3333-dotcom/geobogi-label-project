## 변경 및 수정

- 바코드 속성 창은 데이터 원본부터 시작하며 GS1 설정 버튼을 바로 찾을 수 있습니다. UDI는 선택 기능으로 제공합니다.
- 바코드 종류·크기, 표시문자, GS1 데이터 설정을 분리했습니다.
- 화면을 차지하던 고정 미리보기를 별도 확대 미리보기 창으로 바꿨습니다.
- GS1 목록과 편집 영역이 창 크기에 맞춰 줄어들고, 좁은 화면에서는 AI 선택 메뉴로 전환합니다. 버튼의 잘림과 입력칸 가림을 수정했습니다.
- 데이터 원본별 편집 초안을 유지합니다. 적용·확인은 검증 후 반영하고 취소·Esc·창 닫기는 마지막 적용 상태로 복원합니다.
- 현재 DB 행과 다른 행을 바꿀 때 미리보기 바코드와 표시문자가 함께 갱신됩니다.
- GS1·UDI와 일반 바코드 입력, 바코드 우선 크기 조절, 출력 관리, 프린터 설정, 고객 매뉴얼을 함께 반영했습니다.

## 다운로드 및 업데이트

배포 파일: `채움랩_라벨출력_고객용_20261013_05.zip` (207,643,024바이트).

SHA256: `89897be9a827acc0575081e01f61291660a05a1b14dd4ac0bf852bcad44b69e7`

GitHub 소스 ZIP에는 고객 프로그램 EXE·OCR DLL·고객 DB와 설정을 포함하지 않습니다. 고객 PC에는 **Releases의 전체 배포 ZIP**을 사용하고, 폴더를 모두 풀어 `시작하기.cmd`로 실행하세요.

업데이트 전 기존 `config.ini`, DB, 출력 목록과 도안을 백업합니다. 새 폴더에 압축을 풀고 [업데이트·복구 안내](UPDATE_AND_RECOVERY.md)에 따라 설정과 데이터를 옮깁니다. 이전 `20261013_04` 배포 폴더는 롤백용으로 보존했습니다.

개발 작업 위치는 `개발소스`입니다. 예제 엑셀은 `scripts/create_sample_excel.py`와 `scripts/create_barcode_db.py`에서 만들고 OCR 엔진은 `scripts/install_tesseract_ocr.ps1`로 준비합니다. Zint 실행 엔진과 대응 소스·라이선스는 소스 저장소에 포함합니다.
