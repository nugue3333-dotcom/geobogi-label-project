채움랩 라벨 출력 패키지

그림으로 순서를 확인하려면 같은 폴더의 한눈에_사용안내.pdf를 직접 여세요.
처음 설정, 매일 사용, 인쇄 전 확인, 설치·출력 순서를 4쪽으로 정리했습니다.

1. 처음에는 처음실행_점검.cmd로 설치·설정 상태를 확인하세요.
   이후 시작하기.cmd를 실행하면 라벨 출력 관리 화면이 바로 열립니다.
   이전 번호형 도구 메뉴가 필요하면 '시작하기.cmd menu'를 실행하세요.
2. 처음 실행 점검은 채움랩 기본 글꼴 설치, 실행 전 점검, .gblabel 저장파일 연결, 출력 파일 생성 테스트, 고객 데이터 백업을 순서대로 처리합니다.
   점검 결과는 out\customer_preflight_report.txt와 out\customer_support_package.zip에도 저장됩니다.
   배포 파일 목록은 release_manifest.json과 배포_파일목록.txt에서 확인할 수 있습니다.
   .gblabel 아이콘이나 더블클릭 열기가 풀렸으면 register_label_filetype.cmd를 다시 실행하세요.
3. 프린터설정.exe를 실행해 프린터와 라벨 크기를 입력한 뒤 설정 점검을 누르고 저장하세요.
   업데이트 배포본을 다시 복사해도 기존 config.ini가 있으면 고객 프린터 설정은 자동으로 덮어쓰지 않습니다.
   IP/포트, Windows 프린터 이름, 용지 유형, 간격, DPI가 맞지 않으면 저장 전에 안내가 표시됩니다.
4. 라벨출력관리.exe에서 DB를 연결하고 바코드를 스캔해 인쇄 데이터를 선택하세요.
   중복 검색 결과는 원하는 행을 체크한 뒤 확인을 누르세요. 확인한 행만 인쇄 데이터에 적용되며 선택 항목 인쇄로 출력됩니다.
   인쇄 대상을 선택하지 않으면 전송되지 않습니다. 전체 출력은 '전체 선택'을 직접 누른 뒤 매수를 확인하세요.
   사용법이 필요하면 설정 > 빠른 사용안내 열기 또는 상세 매뉴얼 열기를 누르세요.
5. 문의 전에 버전정보.txt를 확인하세요.
6. 출력 전 01_output_check.cmd로 파일 생성만 다시 확인할 수 있습니다.
   이 배치파일은 라벨작업실행기.exe를 우선 사용하므로 PowerShell 오류 영향을 줄였습니다.
7. 실제 인쇄는 라벨출력관리.exe의 인쇄 메뉴 또는 02_print_labels.cmd를 사용하세요.
   라벨출력관리.exe는 인쇄 직전에 바코드 누락, 출력 매수 오류, 프린터 설정 오류를 먼저 확인합니다.
8. 라벨디자이너.exe에서는 처음 화면의 '예제로 시작'으로 상품 엑셀과 예제 도안을 익힐 수 있습니다.
   기본 템플릿은 빈 라벨입니다. 내 도안은 저장 또는 Ctrl+S로 .gblabel에 보관하세요.
   PSD/사진을 도안 불러오기로 연 뒤 도안 적용을 했다면 '인식 값 검토'에서 원본과 글자·바코드 값을 대조하고 확정하세요.
   미확인 인식 값은 출력이 차단됩니다. 화면의 '반복 출력 화면'은 라벨출력관리.exe로 이동합니다.
9. 이 배포본에는 도안 글자 인식용 tools\ocr 폴더가 포함되어 있습니다. 누락되면 배포 폴더 전체를 다시 받아 설치 담당자에게 문의하세요.
10. PC 교체나 재설치 전에는 출력 관리 화면의 설정 > 고객 데이터 백업 또는 고객데이터_백업.cmd를 실행해 out 폴더의 backup ZIP을 보관하세요.
11. 새 PC에서는 같은 배포 폴더를 복사한 뒤 출력 관리 화면의 설정 > 고객 데이터 복원 또는 고객데이터_복원.cmd로 백업 ZIP을 선택하세요.
    복원 전 현재 데이터는 out 폴더에 pre-restore 백업으로 한 번 더 저장됩니다.
    개별 도안을 옮길 때는 디자이너의 파일 > 이동용 프로젝트 내보내기로 .gbproject를 만든 뒤 새 PC에서 가져오세요.
    원본 상품 엑셀은 별도로 옮겨 다시 연결하고, 그림·글꼴·라벨 크기·프린터 설정과 첫 장 출력을 확인하세요.
    BarTender .btw는 직접 열 수 없습니다. 확장자만 바꾸지 말고 원본 프로그램에서 실제 이미지로 내보낸 뒤 참고 도안으로 다시 작성해야 합니다.
12. 오류 문의 시 라벨출력관리.exe의 설정 > 지원 패키지 생성 메뉴를 누른 뒤
   out\customer_support_package.zip 파일을 함께 전달하면 원인 확인이 빠릅니다.
   이 ZIP에는 OS/저장 위치/파일 점검 요약이 들어가며 원본 상품 DB, 인쇄 데이터, labels.xlsm은 포함되지 않습니다.
13. 자세한 내용은 설치_및_사용_메뉴얼.txt를 확인하세요.

참고: Program Files처럼 권한 제한이 있는 위치에 설치해도 설정, DB, 출력 파일은 자동으로
%LOCALAPPDATA%\ChaeumLAB\LabelPrint 폴더에 저장됩니다. 기존 구버전의 %LOCALAPPDATA%\GeobogiLabel 데이터가 있으면 첫 실행 시 새 폴더로 복사됩니다.
고객 PC 백업 시 설치 폴더와 %LOCALAPPDATA%\ChaeumLAB\LabelPrint 폴더를 함께 보관하세요.
