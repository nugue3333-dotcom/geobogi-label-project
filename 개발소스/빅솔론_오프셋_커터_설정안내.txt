채움랩 프린터 설정 · 2026.10.21.02
1. 사용할 프린터와 용지 종류·크기를 선택합니다.
2. 인쇄 후 작업: 커터 또는 뜯어내기를 선택합니다.
3. 용지 감지 보정: 갭·블랙마크를 기준으로 용지 위치를 미세 보정합니다.
4. 절단·배출 위치 보정: 인쇄 후 절단·정지 위치를 미세 보정합니다.
5. 설정 저장 후 같은 폴더에서 인쇄합니다. 저장만으로 프린터에 전송하지 않습니다.

빅솔론 허용 범위: 203 DPI ±12mm / 300 DPI ±8.4mm / 600 DPI ±4.2mm.
용지 감지 보정의 별도 보정 없음 = 용지의 기본 감지 기준 사용.
절단·배출 위치의 현재 프린터 설정 사용 = 정지 보정 명령 생략. 0 = 기본 위치.
좌우·상하 보정은 글자·바코드 위치이며 절단 위치와 별개입니다.
사용자 펌웨어 확장, 티켓 추가 배출, 본체 유지 전환 메뉴는 제공하지 않습니다.
RAW 출력이므로 드라이버 제한을 자동으로 읽지 않습니다.
커터가 해제되는 기존 장비 현상은 실물 검증이 끝나지 않았습니다.
