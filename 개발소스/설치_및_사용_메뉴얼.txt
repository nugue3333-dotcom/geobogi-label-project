채움랩 라벨 출력 통합 솔루션 설치 및 사용 메뉴얼
문서 버전: 2026.10.20.01

제품 구성
- 시작하기.cmd: 더블클릭하면 라벨 출력 관리가 열립니다. 도구 메뉴는 '시작하기.cmd menu'로 엽니다.
- 처음실행_점검.cmd: 실행 전 점검, .cllabel 저장파일 연결, 출력 파일 생성 테스트, 고객 데이터 백업을 순서대로 실행하는 최초 설치용 점검 파일
- register_label_filetype.cmd: .cllabel 저장파일 아이콘, 더블클릭 열기, 우클릭 인쇄 연결을 PowerShell 없이 등록
- 버전정보.txt: 패키지명, 배포 생성시간, 첫 실행 순서, 지원 문의 시 전달할 정보를 적은 파일
- 고객데이터_백업.cmd: 설정, 상품 DB, 인쇄 데이터, 템플릿, 도안 이미지를 out 폴더의 ZIP으로 백업
- 고객데이터_복원.cmd: 백업 ZIP에서 설정, 상품 DB, 인쇄 데이터, 템플릿, 도안 이미지를 현재 PC로 복원
- 고객환경점검.exe: 고객 PC 배포 상태와 dry-run 출력 점검, 진단 보고서와 지원 ZIP 저장
- 라벨출력관리.exe: 출력 데이터 관리, 바코드 조회, 선택 인쇄, 사용안내 열기, 지원 패키지 생성
- 라벨디자이너.exe: 예제·새 라벨 작성, 상품 엑셀 연결, 인식 값 검토, .cllabel 저장, .clproject 이동
- 프린터설정.exe: 프린터/라벨/바코드/미디어 설정
- 라벨작업실행기.exe: 01/02/03/04 배치파일에서 사용하는 내부 작업 실행기
- 라벨출력엔진.exe: 실제 출력 명령 생성 및 프린터 전송 엔진
- config.ini: 현재 프린터와 라벨 설정
- config.example.ini: 설정 예시
- release_manifest.json: 배포 파일 해시와 구성 검증용 목록
- 배포_파일목록.txt: 고객이 바로 읽을 수 있는 배포 파일 목록
- barcode_db.xlsx: 상품 DB 기본 파일
- print_queue.xlsx: 인쇄 데이터 파일
- templates/default_label.json: 개체가 없는 빈 기본 라벨
- templates/sample_excel_product.cllabel: 상품 엑셀 연결 예제 라벨
- sample_direct_open.cllabel: 라벨디자이너 샘플 파일
- out 폴더: 출력 명령 파일, 미리보기 결과, 고객환경점검 진단 보고서와 지원 ZIP 저장 위치

1. 설치
1) 배포 압축 파일을 원하는 위치에 풉니다.
2) 폴더 안의 파일 이름을 변경하지 않습니다.
3) Windows 보안 경고가 나오면 고객 PC 정책에 맞게 허용합니다.
4) 처음실행_점검.cmd로 설치 상태를 확인한 뒤 시작하기.cmd에서 출력 관리 화면을 엽니다.
   또는 처음실행_점검.cmd를 바로 실행합니다.
5) 처음 실행 점검으로 필수 파일, 설정, 엑셀, 인쇄 데이터 바코드/매수, .cllabel 저장파일 연결, 출력 폴더 쓰기 권한, dry-run 결과, 고객 데이터 백업을 확인합니다.
   결과는 out\customer_preflight_report.txt와 out\customer_support_package.zip에도 저장됩니다.
   release_manifest.json 기준으로 실행 파일과 안내문 누락 여부도 함께 확인합니다.
   설치 후에도 라벨출력관리.exe의 도움말 > 지원 패키지 생성 메뉴에서 같은 점검 ZIP을 다시 만들 수 있습니다.
6) .cllabel 아이콘이나 더블클릭 열기가 풀렸으면 '시작하기.cmd menu'에서 저장파일 연결 등록을 선택하거나 register_label_filetype.cmd를 실행합니다.
7) Excel 매크로 방식도 사용할 경우 00_install_trusted_location.cmd를 1회 실행합니다.
8) 일반 사용은 라벨출력관리.exe, 라벨디자이너.exe, 프린터설정.exe만 실행하면 됩니다.
9) 사용법이 필요하면 라벨출력관리.exe의 도움말 > 빠른 사용안내 열기 또는 고객용 매뉴얼을 사용합니다.
10) 지원 문의 전에는 '시작하기.cmd menu'의 버전 정보 보기 또는 버전정보.txt를 확인합니다.

권장 설치 위치
- C:\ChaeumLAB\LabelPrint
- 또는 바탕화면\채움랩_라벨출력

주의
- Program Files처럼 권한 제한이 강한 위치에 설치해도 실행은 가능합니다.
- 이 경우 설정, DB, 인쇄 데이터, 출력 로그는 자동으로 %LOCALAPPDATA%\ChaeumLAB\LabelPrint 폴더에 저장됩니다.
- 구버전 %LOCALAPPDATA%\GeobogiLabel 데이터가 있으면 첫 실행 시 새 폴더로 복사됩니다.
- 업데이트 배포본을 다시 복사해도 기존 config.ini가 있으면 고객 프린터 설정은 자동으로 덮어쓰지 않습니다.
  기본값으로 되돌릴 때만 백업 후 config.example.ini를 참고하세요.
- 고객 PC를 교체하거나 백업할 때는 설치 폴더와 %LOCALAPPDATA%\ChaeumLAB\LabelPrint 폴더를 함께 보관하세요.
- 고객데이터_백업.cmd를 실행하면 운영 데이터만 out\chaeumlab_customer_backup_*.zip으로 묶어 보관할 수 있습니다.
- 새 PC에서는 같은 배포 폴더를 복사한 뒤 고객데이터_복원.cmd로 백업 ZIP을 선택하세요.
- 복원 전 현재 데이터는 out 폴더에 pre-restore 백업으로 자동 저장됩니다.
- OneDrive 동기화 폴더에서는 파일 잠금이 생길 수 있습니다.

2. 최초 프린터 설정
1) 프린터설정.exe를 실행합니다.
2) 프린터 브랜드를 선택합니다.
   - BIXOLON
   - TSC
   - Zebra
   - SEWOO
3) 연결 방식을 선택합니다.
   - LAN: 프린터 IP와 포트 9100 입력
   - USB/드라이버: Windows 프린터 이름 입력
4) 라벨 크기를 실제 라벨지와 맞춥니다.
   - 폭 mm
   - 높이 mm
   - DPI
   - gap mm
5) 용지 유형을 선택합니다.
   - 갭 용지
   - 블랙마크 용지
   - 연속 용지
   갭 용지와 블랙마크 용지는 gap mm를 0보다 크게 입력해야 합니다. 연속 용지는 0을 권장합니다.
6) 인쇄 방식을 선택합니다.
   - 감열
   - 열전사
7) 인쇄후작업을 선택합니다.
   - 뜯어내기
   - 커터
   - 필러
8) 설정 점검을 눌러 IP/포트, Windows 프린터 이름, 용지 유형, 간격, DPI 오류가 없는지 확인합니다.
9) 저장 후 프로그램을 다시 실행합니다.
10) 값을 변경하면 창 제목 끝에 * 표시가 붙습니다. 저장하지 않은 상태에서 현재 설정을 다시 불러오거나 창을 닫으면 확인창이 표시됩니다.

중요
- 커터/필러는 장비에 실제 옵션이 장착되어 있어야 동작합니다.
- 필러 명령은 TSC, Zebra에서 지원합니다.
- BIXOLON/SLCS는 필러 명령 근거가 확인되기 전까지 뜯어내기 또는 커터만 선택하세요.
- 프린터 명령 전송 성공과 실제 라벨 출력 성공은 다릅니다. 출력 후 장비 상태와 라벨 결과를 확인하세요.

3. 상품 DB 준비
1) 라벨출력관리.exe를 실행합니다.
2) 사용법을 확인해야 하면 도움말 > 빠른 사용안내 열기 또는 도움말 > 고객용 매뉴얼을 누릅니다.
3) 상품 엑셀 연결을 누릅니다.
4) 상품 DB 엑셀 파일을 선택합니다.
5) 첫 줄은 반드시 컬럼명이어야 합니다.

권장 컬럼 예시
- 바코드
- 가격
- 품명
- 날짜
- 상품코드
- LOT
- 수량

필수 컬럼
- 바코드

출력 반영 방식
- DB에서 불러온 컬럼명과 값이 인쇄 데이터에 보존됩니다.
- 출력 시 텍스트는 컬럼명: 값 형태로 왼쪽 정렬됩니다. 표시할 항목이 라벨 높이의 용량을 넘으면 인쇄를 중지하므로 출력용 엑셀 열과 실제 용지 높이를 확인하세요.
- 바코드는 중앙 정렬됩니다.

4. 인쇄 데이터 선택
1) 라벨출력관리.exe 상단 DB 상품조회 입력칸에 커서를 둡니다.
2) 스캐너로 바코드를 스캔합니다.
3) 인쇄 데이터에서 같은 바코드 행을 찾아 선택합니다.
4) 같은 바코드가 없으면 경고가 표시됩니다.

도구 메뉴
- 인쇄: 선택한 행의 매수를 확인한 뒤 인쇄합니다.
- 전체 선택: 인쇄 데이터 전체를 선택합니다.
- 선택 해제: 선택을 모두 해제합니다.

선택 인쇄 기준
- 체크된 행이 있으면 체크된 행만 인쇄합니다.
- 체크된 행이 없으면 전체 항목에 같은 매수가 적용됩니다. 대상 건수와 총 매수는 인쇄 매수 선택 창에서 확인합니다.
- 라벨출력관리.exe는 인쇄 직전 바코드 누락, 출력 매수 오류, config.ini 프린터 설정 오류를 먼저 점검합니다.
- 오류가 표시되면 해당 행 또는 프린터 설정을 수정한 뒤 다시 인쇄합니다.

5. 실제 인쇄 전 점검
0) 처음 설치한 PC에서는 처음실행_점검.cmd를 먼저 실행합니다.
   오류가 있으면 out\customer_support_package.zip을 지원 담당자에게 전달합니다.
1) 01_output_check.cmd를 실행합니다.
2) out 폴더에 명령 파일이 생성되는지 확인합니다.
   이 경로는 라벨작업실행기.exe가 PowerShell 없이 labels.xlsm을 print_queue.xlsx로 변환한 뒤 실행합니다.
3) 생성 파일에 오류가 없으면 02_print_labels.cmd 또는 라벨출력관리.exe의 인쇄를 실행합니다.

라벨 출력 레이아웃
- 텍스트: 왼쪽 정렬
- 바코드: 중앙 정렬
- 크기: 라벨 폭/높이/DPI 기준 자동 조정
- 출력 데이터: DB 컬럼 기준 반영

6. 라벨디자이너 사용
1) 라벨디자이너.exe를 실행합니다.
2) 처음 화면에서 예제로 시작, 새 라벨, 최근 라벨 열기 중 고릅니다.
   예제는 별도 파일입니다. templates/default_label.json은 개체가 없는 빈 기본 라벨입니다.
3) 용지 설정에서 실제 라벨 가로·세로(mm)를 저장한 뒤 아이콘 도구로 텍스트, 1D/2D 바코드, 그림, 표, 선, 박스를 추가합니다.
4) 상품 엑셀 연결에서 .xlsx/.xlsm 파일을 열고 개체에 필요한 열을 연결합니다. 상품 선택에서 출력할 행만 체크합니다.
   바코드 앞자리 0이 중요하면 Excel 셀을 문자로 저장하세요. 단순 0 채우기 숫자 서식은 화면 값을 읽지만 복잡한 서식·15자리 초과 숫자는 문자로 고쳐야 합니다.
5) 개체를 더블클릭해 위치, 크기, 글자 크기와 방향을 조정합니다. 오른쪽은 상품 DB 메뉴만 표시합니다. 상단 좌우 가운데 정렬·상하 가운데 정렬로 각각 가로·세로 중심에 배치합니다.
   방향은 0도, 90도, 180도, 270도 중 고릅니다. 회전 후 라벨 경계를 확인하세요.
6) 저장 또는 Ctrl+S로 .cllabel 파일을 저장합니다. 파일명 옆 *는 미저장 변경을 뜻합니다.
7) Ctrl+Z/Ctrl+Y로 실행취소/다시실행합니다. 비정상 종료 후 복구 제안은 저장 원본을 덮어쓰지 않는 작업 사본입니다.
8) Ctrl+클릭으로 여러 개체를 선택하고 복제·그룹·잠금·정렬을 사용합니다. 방향키는 1mm, Shift+방향키는 0.1mm 이동합니다.
   화면 맞춤과 확대·축소는 보기 크기만 바꿉니다. 100% 화면 배율을 실물 크기로 판단하지 마세요.

안전한 출력 순서
- 인쇄파일 생성은 프린터로 보내지 않고 결과 파일만 생성합니다.
- 실제 전송 전 경계 밖 개체, 비어 있는 필수 값, 글자 축소·작은 QR 경고를 확인합니다.
- 인쇄 전 대상·매수를 확인합니다. 프린터 전송 완료는 실제 라벨 출력 완료가 아닙니다.
- 전송이 중단되어 상태가 미확인인 항목은 실물을 먼저 확인한 뒤 전송됨 또는 재전송 대상으로 직접 결정합니다.
- 실제 라벨 배출·위치와 1D/2D 바코드 판독은 장비에서 확인합니다.

PSD/사진 파일을 참고 도안으로 사용하는 방법
1) 용지 설정에서 프린터설정.exe를 열어 실제 라벨 가로·세로(mm)를 저장합니다. 디자이너의 읽기 전용 공통 규격 표시를 확인합니다.
2) 개체 도구에서 도안 불러오기를 누릅니다.
3) PSD, PNG, JPG, BMP, GIF, TIFF, WEBP 파일을 선택합니다.
4) 선택한 파일은 assets/images 폴더에 참고용 PNG로 저장되고, 현재 라벨 크기에 맞춰 참고 도안으로 들어갑니다.
5) 도안 적용을 눌러 그림을 분석합니다.
6) 선, 박스, 텍스트 후보, 바코드 후보가 편집 가능한 개체로 생성됩니다.
7) 인식 값 검토에서 원본 이미지와 글자·바코드 후보를 나란히 보고 임시 값을 직접 수정해 확정합니다.
8) 미확인 인식 값이 있으면 출력을 할 수 없습니다. 인쇄파일 생성으로 먼저 결과를 확인한 뒤 1장을 전송합니다.

다른 PC로 도안을 옮기는 방법
1) 파일 메뉴의 이동 프로젝트 내보내기로 .clproject 파일을 만듭니다. 필요한 도안 이미지를 함께 옮깁니다.
2) 새 PC에서 이동 프로젝트 가져오기를 선택합니다. 기존 고객 데이터 원본은 덮어쓰지 않습니다.

[2D 바코드 크기 우선 개정 2026.10.13.01]
1. 2D 개체를 더블클릭하여 2D 크기·문자 배치에서 크기 방식을 확인합니다.
2. 새 2D 개체는 바코드 크기 우선으로 시작합니다. 기존 도안은 기존 배치를 유지하며 이 창에서 직접 전환합니다.
3. 바코드 한 변(mm) 또는 바코드 가로(mm)·바코드 세로(mm)는 표시문자를 제외하고 필수 여백을 포함한 코드 영역의 목표입니다. 실제 크기 확인에서 현재 데이터와 출력 DPI 기준 실제 mm·모듈 도트를 확인합니다.
4. 모듈 크기 고정은 고급 방식입니다. 도트 기준과 mm 목표를 동시에 독립 편집하지 않습니다. 데이터 길이나 코드 버전이 달라지면 전체 크기를 다시 확인합니다.

1. 프린터 설정의 용지 구역에서 실제 라벨 폭·길이를 mm로 입력합니다. 50.5 × 30.25, 101.6 × 152.4처럼 소수점도 저장됩니다.
