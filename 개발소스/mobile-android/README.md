# 라벨 출력 모바일 Android 앱

Android 휴대폰에서 라벨 프린터로 직접 출력하는 모바일 앱입니다.

## 지원 연결 방식

- 무선랜 / LAN 전용: 프린터 IP와 포트로 RAW 명령을 전송합니다.
- 기본 포트는 `9100`입니다.
- USB, Windows 드라이버 큐, Bluetooth 출력은 모바일 앱에서 제외했습니다.

## 지원 브랜드

- BIXOLON / 빅솔론: SLCS 명령, 한글 인코딩 `MS949`
- TSC: TSPL 명령, 한글 인코딩 `MS949`
- Zebra / 제브라: ZPL 명령, 한글 인코딩 `UTF-8`
- SEWOO / 세우테크: ZPL 호환 모델 기준, 한글 인코딩 `UTF-8`

## 앱에서 설정하는 항목

- 프린터 IP, 포트
- 프린터 브랜드
- 인쇄 방식: 감열 / 리본 없음, 열전사 / 리본 사용
- 인쇄후작업: 뜯어내기, 커터, 필러
- 용지 유형: 갭 용지, 블랙마크 용지, 연속 용지
- 용지: 가로(mm), 세로(mm), 라벨 간격(mm), DPI
- 라벨 데이터: 품목 코드, 품목명, 바코드, LOT 번호, 수량, 출력 매수

## 빌드 방법

1. Android Studio를 설치합니다.
2. Android Studio에서 이 폴더를 엽니다.
   - `.\개발소스\mobile-android`
3. Android SDK Platform 35와 JDK 17 환경으로 Gradle Sync를 실행합니다.
4. `Build > Build Bundle(s) / APK(s) > Build APK(s)`를 실행합니다.

현재 `dist` 폴더의 APK는 이전 산출물입니다. 무선 LAN 전용 UI, 세우테크, 인쇄후작업, 용지 유형 변경사항은 Android Studio에서 새로 빌드한 APK에만 반영됩니다.

## 사용 전 준비

1. 휴대폰과 라벨 프린터가 같은 네트워크에 있어야 합니다.
2. 프린터의 IP를 확인합니다.
3. 앱에서 IP, 포트, 브랜드, 용지 크기를 입력합니다.
4. `테스트 라벨 전송`으로 1장 출력 흐름을 확인합니다.

## 제한 사항

- 현재 모바일 앱은 수동 입력한 테스트 라벨 1건을 전송하는 초안입니다.
- 엑셀 DB 동기화, 라벨 디자이너 템플릿 불러오기, 스캐너 연동은 아직 연결하지 않았습니다.
- SEWOO는 ZPL 호환 세우테크 모델 기준입니다. 모델별 전용 명령은 공식 매뉴얼 확인 후 분리해야 합니다.
