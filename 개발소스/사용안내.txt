채움랩 라벨 출력 패키지 빠른 사용안내
문서 버전: 2026.10.20.01

1. 먼저 실행할 파일
- 시작하기.cmd: 라벨 출력 관리 화면을 바로 엽니다. 이전 번호형 도구 메뉴는 '시작하기.cmd menu'로 엽니다.
- 처음실행_점검.cmd: 채움랩 기본 글꼴 설치, 실행 전 점검, .cllabel 저장파일 연결, 출력 파일 생성 테스트, 고객 데이터 백업을 순서대로 실행하는 최초 설치용 점검 파일
- register_label_filetype.cmd: .cllabel 저장파일 아이콘, 더블클릭 열기, 우클릭 인쇄 연결을 PowerShell 없이 등록
- 버전정보.txt: 패키지명, 배포 생성시간, 첫 실행 순서, 지원 문의 시 전달할 정보를 적은 파일
- 고객데이터_백업.cmd: 설정, 상품 DB, 인쇄 데이터, 템플릿, 도안 이미지를 out 폴더의 ZIP으로 백업
- 고객데이터_복원.cmd: 백업 ZIP에서 설정, 상품 DB, 인쇄 데이터, 템플릿, 도안 이미지를 현재 PC로 복원
- 고객환경점검.exe: 고객 PC 배포 상태, 설정, 엑셀, 인쇄 데이터 바코드/매수, 출력 폴더, dry-run 출력 점검 및 지원 ZIP 저장
- 라벨출력관리.exe: DB 조회, 출력 데이터 선택, 인쇄 실행, 사용안내 열기, 지원 패키지 생성
- 프린터설정.exe: 프린터 브랜드, 연결 방식, 라벨 크기, 용지 유형, 커터/필러/뜯어내기 설정과 저장 전 점검
- 라벨디자이너.exe: 예제·새 라벨 작성, 상품 엑셀 연결, 인식 값 검토, .cllabel 저장, .clproject 이동
- 라벨작업실행기.exe: 01/02/03/04 배치파일에서 사용하는 내부 작업 실행기
- release_manifest.json / 배포_파일목록.txt: 고객 배포 파일 구성과 해시 확인용 목록

2. 최초 설치
- 압축을 푼 폴더 전체를 한 위치에 보관하세요.
- 실행 파일 이름과 config.ini, print_queue.xlsx, barcode_db.xlsx 이름은 변경하지 마세요.
- Windows 보안 경고가 나오면 고객 PC 정책에 맞게 허용 후 실행하세요.
- 처음실행_점검.cmd를 먼저 실행하세요. 이후 시작하기.cmd에서 출력 관리 화면을 여세요.
- 처음 실행 점검은 머니그라피 Rounded 기본 글꼴 설치, 실행 전 점검, .cllabel 저장파일 연결, 출력 파일 생성 테스트, 고객 데이터 백업을 한 번에 실행합니다.
- .cllabel 아이콘이나 더블클릭 열기가 풀렸으면 register_label_filetype.cmd를 실행하세요.
- 00_고객PC_실행전점검.cmd는 단독 점검이 필요할 때 실행하세요.
- 점검 결과는 out\customer_preflight_report.txt와 out\customer_support_package.zip에 자동 저장됩니다.
- 지원 문의 시 버전정보.txt 내용을 함께 확인하세요.
- Program Files처럼 쓰기 권한이 제한된 위치에 설치하면 설정, DB, 출력 파일은 자동으로
  %LOCALAPPDATA%\ChaeumLAB\LabelPrint 폴더에 저장됩니다.
- 구버전 %LOCALAPPDATA%\GeobogiLabel 데이터가 있으면 첫 실행 시 새 폴더로 복사됩니다.
- 업데이트 배포본을 다시 복사해도 기존 config.ini가 있으면 고객 프린터 설정은 자동으로 덮어쓰지 않습니다.
  기본값으로 되돌릴 때만 백업 후 config.example.ini를 참고하세요.
- PC 교체나 백업 시 설치 폴더와 %LOCALAPPDATA%\ChaeumLAB\LabelPrint 폴더를 함께 보관하세요.
- PC 교체 전에는 고객데이터_백업.cmd를 실행해 out\chaeumlab_customer_backup_*.zip 파일을 별도로 보관하세요.
- 새 PC에서는 고객데이터_복원.cmd를 실행해 백업 ZIP을 선택한 뒤 01_output_check.cmd로 복원 결과를 확인하세요.

3. 프린터 설정
- 프린터설정.exe를 실행합니다.
- 브랜드: BIXOLON, TSC, Zebra, SEWOO 중 선택합니다.
- 연결 방식: LAN이면 IP/포트, USB/Windows 드라이버면 Windows 프린터 이름을 설정합니다.
- 라벨 크기: 실제 라벨지 폭/높이, DPI, gap 값을 입력합니다.
- 용지 유형: 갭 용지, 블랙마크 용지, 연속 용지 중 실제 라벨지를 선택합니다.
- 갭 용지와 블랙마크 용지는 gap 값을 0보다 크게 입력해야 합니다. 연속 용지는 gap 값을 0으로 두는 것을 권장합니다.
- 미디어 옵션: 뜯어내기, 커터, 필러 중 실제 장비 옵션에 맞게 선택합니다.
- 설정 점검을 눌러 IP/포트, Windows 프린터 이름, 용지 유형, 간격, DPI 오류가 없는지 확인한 뒤 저장하세요.
- 값을 바꾸면 창 제목 끝에 * 표시가 붙습니다. 저장하지 않은 상태에서 현재 설정을 다시 불러오거나 창을 닫으면 확인창이 표시됩니다.
- 저장 후 라벨출력관리.exe를 다시 실행하세요.

4. DB와 인쇄 데이터
- 라벨출력관리.exe를 실행합니다.
- 도움말 메뉴의 빠른 사용안내 열기, 고객용 매뉴얼에서 현재 폴더의 설명서를 바로 열 수 있습니다.
- 파일 메뉴에서 상품 엑셀 연결을 누르고 상품 DB 엑셀을 선택합니다.
- DB 엑셀 첫 줄은 헤더입니다. 예: 바코드, 가격, 품명
- 바코드 컬럼은 반드시 있어야 합니다.
- 앞자리 0이 있는 바코드는 Excel에서 문자로 저장하세요. 숫자 셀의 단순 0 채우기 서식은 화면 표시값을 읽지만, 복잡한 서식과 15자리 초과 숫자는 원본 확인 후 문자로 고쳐야 합니다.
- DB에서 불러온 열과 값은 인쇄 데이터에 보존됩니다. 출력할 항목이 라벨 높이에 표시 가능한 수를 넘으면 인쇄를 중지합니다. 필요한 열을 담은 출력용 엑셀과 실제 용지 높이를 확인하세요.

5. 스캔 동작
- 상단 DB 상품조회 입력칸에 커서를 둡니다.
- 스캐너로 바코드를 스캔하고 Enter가 입력되면 인쇄 데이터에서 같은 바코드를 찾아 선택합니다.
- 같은 바코드가 없으면 "인쇄 데이터에서 해당 바코드를 찾을 수 없습니다." 경고가 표시됩니다.
- 검색 결과가 여러 건이면 중복 DB 항목 선택 창에서 원하는 행을 체크하고 확인을 누릅니다.
- 확인한 행만 인쇄 데이터 탭에 체크되며, 이전에 체크했던 다른 행은 선택에서 제외됩니다.

6. 인쇄
- 도구 메뉴에는 인쇄, 전체 선택, 선택 해제가 있습니다.
- 선택된 행이 있으면 선택된 행만 인쇄합니다.
- 체크한 행이 없으면 전체 항목이 대상입니다. 인쇄 수량 창에서 대상 건수와 총 매수를 확인하고, 취소하면 명령을 전송하지 않습니다.
- 인쇄 직전 바코드 누락, 출력 매수 오류, config.ini 프린터 설정 오류를 점검합니다.
- 오류가 표시되면 해당 행 또는 프린터 설정을 수정한 뒤 다시 인쇄하세요.
- 프린터 전송 완료 팝업은 프로그램이 명령을 보냈다는 뜻입니다. 실제 라벨 배출·위치·바코드 판독은 장비에서 확인하세요.

7. 출력 형식
- 텍스트는 DB에서 불러온 컬럼명과 값 기준으로 왼쪽 정렬됩니다.
- 바코드는 라벨 중앙에 배치됩니다.
- 글자와 바코드 크기는 라벨 크기와 DPI에 맞게 자동 조정됩니다.

8. 라벨디자이너
- 처음 화면에서 예제로 시작, 새 라벨, 최근 라벨 열기 중 고릅니다. 예제는 별도 도안이며 기본 템플릿은 빈 라벨입니다.
- 상품 엑셀 연결에서 .xlsx/.xlsm을 열고 개체에 필요한 열을 연결합니다. 상품 선택에서 출력할 행만 체크합니다.
- 내 도안은 저장 또는 Ctrl+S로 .cllabel에 보관합니다. 파일명 옆 *는 아직 저장하지 않은 변경을 뜻합니다.
- Ctrl+클릭으로 여러 개체를 선택하고 복제·그룹·잠금·정렬을 사용할 수 있습니다. 방향키는 1mm, Shift+방향키는 0.1mm 이동합니다.
- Ctrl+Z/Ctrl+Y로 되돌리기/다시실행을 합니다. 화면 맞춤과 확대·축소는 보기 크기만 바꿉니다.
- 도안 불러오기로 PSD/PNG/JPG를 열어 도안 적용을 누르면 편집 가능한 후보 개체가 생성됩니다.
- 인식 값 검토에서 원본 이미지와 후보 글자·바코드를 비교하고 임시 값은 직접 수정해 확정합니다. 미확인 값은 출력할 수 없습니다.
- 인쇄 전 경계 밖 개체, 비어 있는 필수 값, 글자 축소·작은 QR 경고를 처리합니다.
- 인쇄파일 생성은 프린터로 보내지 않습니다. 실제 전송 후에는 라벨 배출과 1D/2D 판독을 확인합니다.
- 중단된 전송 상태가 미확인이라면 실물을 먼저 보고 전송됨 또는 재전송 대상을 직접 선택합니다. 중복 출력 가능성에 주의하세요.
- 텍스트·바코드·그림·박스·선·표의 방향은 0도, 90도, 180도, 270도로 바꿀 수 있습니다. 회전 후 라벨 경계를 확인합니다.
- 다른 PC로 옮길 때는 파일 > 이동 프로젝트 내보내기에서 .clproject를 만든 뒤 가져옵니다. 원본 상품 엑셀은 별도로 옮겨 다시 연결합니다.
- BarTender .btw 파일은 직접 열 수 없습니다. 실제 이미지로 내보내 참고 도안으로 다시 만들고 필드·값·인쇄 설정을 확인합니다.

9. 점검
- 처음실행_점검.cmd: 최초 설치 시 실행 전 점검, 출력 파일 생성 테스트, 고객 데이터 백업을 순서대로 실행합니다.
- 00_고객PC_실행전점검.cmd: 필수 파일, 설정, 엑셀, 인쇄 데이터 바코드/매수, 템플릿, 출력 폴더 쓰기 권한, dry-run을 한 번에 확인하고 지원 ZIP을 저장합니다.
- release_manifest.json 기준으로 실행 파일과 안내문이 배포 후 누락되거나 바뀌었는지도 확인합니다.
- 버전정보.txt: 현재 패키지명, 배포 생성시간, 문의 시 필요한 기본 정보를 확인합니다.
- 라벨출력관리.exe > 도움말 > 지원 패키지 생성: 프로그램 안에서 같은 점검을 실행하고 지원 ZIP을 다시 생성합니다.
- out\customer_support_package.zip: 지원 담당자에게 전달할 점검 패키지입니다. OS/저장 위치/파일 점검 요약은 포함하지만 원본 상품 DB, 인쇄 데이터, labels.xlsm은 포함하지 않습니다.
- 01_output_check.cmd: 프린터로 보내지 않고 출력 명령 파일만 생성합니다.
- 02_print_labels.cmd: 실제 프린터로 인쇄합니다.
- 01/02 배치파일은 라벨작업실행기.exe를 우선 사용합니다. PowerShell 실행 오류가 있어도
  일반적인 출력 점검과 인쇄 명령 생성은 이 실행기로 처리됩니다.
- 03_open_output_folder.cmd: 출력 명령 파일 폴더를 엽니다.
- 04_open_last_log.cmd: 마지막 실행 로그를 엽니다.

10. 고객 데이터 백업/복원
- 출력 관리 화면의 파일 > 고객 데이터 백업 또는 고객데이터_백업.cmd를 실행합니다.
- 백업 파일은 out\chaeumlab_customer_backup_YYYYMMDD_HHMMSS.zip 형식으로 저장됩니다.
- 백업 ZIP에는 config.ini, barcode_db.xlsx, print_queue.xlsx, labels.xlsm, templates, db, assets/images 폴더가 포함됩니다.
- EXE 실행 파일, out 폴더, 실행 로그, 지원 ZIP은 백업에 포함하지 않습니다.
- 새 PC나 재설치 후에는 출력 관리 화면의 파일 > 고객 데이터 복원 또는 고객데이터_복원.cmd를 실행합니다.
- 복원할 backup ZIP을 선택하면 현재 데이터가 먼저 out 폴더에 pre-restore 백업으로 저장된 뒤 복원됩니다.
- 복원 후 01_output_check.cmd 또는 라벨출력관리.exe의 인쇄파일 생성으로 데이터와 템플릿이 맞는지 확인하세요.

11. 문제 발생 시
- Permission denied 또는 designer_test_config.ini 권한 오류가 나오면 구버전 실행 파일일 수 있습니다.
  최신 배포본으로 교체한 뒤 다시 실행하세요.
- 인쇄가 예전 값으로 나오면 라벨출력관리.exe에서 인쇄 데이터를 저장한 뒤 다시 인쇄하세요.
- 바코드가 작거나 스캔이 안 되면 프린터설정.exe에서 라벨 크기와 DPI가 실제 장비와 맞는지 확인하세요.
- LAN 프린터가 반응하지 않으면 IP, 포트 9100, 같은 네트워크 연결 여부를 확인하세요.
- 커터/필러가 동작하지 않으면 실제 장비 옵션이 장착되어 있는지 먼저 확인하세요.
- 원인 확인을 요청할 때는 라벨출력관리.exe의 도움말 > 지원 패키지 생성 메뉴를 누른 뒤 out\customer_support_package.zip을 전달하세요.
- 이때 버전정보.txt 내용도 함께 전달하면 어떤 배포본인지 바로 확인할 수 있습니다.
  ZIP 안의 environment_summary.txt, file_inventory.txt, release_manifest_summary.txt로 설치 위치와 누락 파일을 빠르게 확인할 수 있습니다.

[2D 바코드 크기 우선 개정 2026.10.13.01]

3. 바코드 한 변(mm) 또는 바코드 가로(mm)·바코드 세로(mm)는 표시문자를 제외하고 필수 여백을 포함한 코드 영역의 목표입니다. 실제 크기 확인에서 현재 데이터와 출력 DPI 기준 실제 mm·모듈 도트를 확인합니다.

5. 문자 위치는 오른쪽 또는 아래, 문자 간격(mm)은 필수 여백 바깥 간격입니다. 문자 크기는 자동 맞춤 또는 지정 크기를 선택합니다. 문자를 바꾸어도 확정한 코드 크기를 축소하지 않습니다.
6. 개체 전체 가로·세로는 바코드와 표시문자에서 계산합니다. 문자 공간 오류 중에도 손잡이로 조절하며 현재 라벨에 맞추기 또는 문자 아래 배치를 검토합니다. 값 잘림이나 자동 코드 축소로 해결하지 않습니다.
7. 전체 데이터 검증과 인쇄파일에서 크기·라벨 경계를 확인합니다. 목표 mm는 모든 용도의 승인값이 아닙니다. 실제 프린터·스캐너로 한 항목·1매를 확인합니다. 1D의 기존 배치는 유지합니다.

2. 시험용 완성 예제로 시작은 시험용 값입니다. 적용 후 실제 발급·관리하는 번호 또는 DB 열로 바꿉니다. 필수 AI 선택은 부족한 조합을 함께 보여 주며 실제 번호를 임의 생성하지 않습니다. AI21에는 해당 제품의 식별번호가 필요하고 AI37에는 00 및 02/8026 조합을 확인합니다.
3. 새 AI와 수정 중인 행은 검증·적용 전에 자동 반영합니다. 한 AI의 값 칸에는 값만 넣고, (01) 등을 포함한 전체 문자열은 전체 GS1 데이터 가져오기를 사용합니다. 가져오기 미리보기에서 선행 0·항목·값을 확인합니다.

8. 문자 공간·라벨 경계 오류 중에도 코드 크기 조절·이동·실행취소를 사용합니다. 현재 라벨에 맞추기와 문자 아래 배치를 검토한 뒤 다시 확인합니다. 전체 가로·세로는 코드와 표시문자에서 계산하므로 따로 입력하지 않습니다. 모듈 크기 고정은 도트 변경으로 조절하며 손잡이 조절은 잠깁니다.

# 용지 설정과 도안 인식 · 2026.10.20.01

1. 프린터 설정의 용지 구역에서 실제 라벨 폭·길이를 mm로 입력합니다. 50.5 × 30.25, 101.6 × 152.4처럼 소수점도 저장됩니다.
2. 세로 / 가로 / 세로 180도 / 가로 180도를 선택합니다. 가로는 내용 전체를 반시계 90도 회전합니다. 가로 작업면은 폭·높이가 바뀌며 실제 용지 폭·길이는 그대로입니다.
3. 좌우·상하 보정은 인쇄된 용지 기준입니다. 양수는 오른쪽·아래쪽입니다. 내용이 용지 밖으로 나가면 인쇄를 차단하므로 여백이나 보정값을 조정합니다.
4. 용지 감지 보정과 절단·배출 위치 보정은 용지 영역에서 조정합니다. TSC에서 현재 설정을 사용하면 GAP/BLINE 명령 전체를 생략하고, 직접 0mm를 입력하면 선택한 용지 종류와 추가 이송 0을 전송합니다. OFFSET 공급 보정은 별도 항목입니다.
5. 도안의 규격·방향이 현재 용지와 다르면 적용 방법을 선택합니다. 도안은 규격·방향을 보관하고 장비 보정은 config.ini에 보관합니다.
6. 도안 가져오기는 실제 이미지의 누운 글자를 인식용 복사본에서 회전 보정합니다. 인식 결과는 원래 도안 위치·방향으로 돌아옵니다. 인식 값 전체 확인에서 원본·영문·한글·숫자·앞자리 0을 대조합니다.
7. 이미 잘못 읽힌 문자열은 인쇄 방향 변경만으로 복구되지 않습니다. 원본을 다시 적용한 뒤 결과를 확인하세요. 직접 고친 기존 도안은 먼저 다른 이름으로 저장하세요.
8. BarTender 파일(.btw)을 PNG로 이름만 바꾸면 이미지로 변환되지 않습니다. 원본 프로그램에서 충분한 해상도로 이미지/PDF를 내보내 사용하세요. 내장 미리보기는 실제 출력 이미지보다 해상도가 낮을 수 있습니다.

저장 후 인쇄파일을 생성하고 미리보기·데이터를 먼저 확인합니다. 실제 장비에서 1매의 규격·방향·위치·배출 정지 위치와 다음 장 시작 위치·1D/2D 판독을 확인해야 합니다.

[제조사별 용지 배출 보정 · 2026.10.20.01]
용지 감지 보정과 절단·배출 위치 보정은 프린터 설정의 용지 영역에서 조정합니다. TSC의 ‘현재 프린터 설정 사용’은 GAP/BLINE 명령 전체를 생략해 프린터에 저장된 용지 종류와 추가 이송을 유지합니다. 직접 0mm를 입력하면 선택한 갭/블랙마크 명령과 추가 이송 0을 적용합니다.
BIXOLON 용지 감지 보정과 절단·배출 위치 보정은 ±12mm와 ±100도트 중 좁은 범위에서 입력합니다. 203 DPI는 ±12mm, 300 DPI는 ±8.4mm, 600 DPI는 ±4.2mm입니다. 별도 보정 없음과 현재 프린터 설정 사용은 각각 해당 보정 명령을 생략하며, 0은 기본 위치를 지정합니다. 커터 사용 여부는 인쇄 후 작업에서 선택합니다. RAW 출력은 드라이버 값을 자동 조회하지 않으므로 실제 장비에서 첫 장과 다음 장의 배출·커터 위치를 확인하세요.
TSC: 갭/블랙마크 추가 이송은 GAP/BLINE의 두 번째 값으로 0~용지 길이입니다. 공급 오프셋(OFFSET)은 별도 항목으로 -25.4~25.4mm입니다.
빅솔론 절취·커터 정지 보정 TA는 별도 기능이며 ±100도트 범위이고 프린터에 영구 저장됩니다. 기존 값을 기록하고 실제 모델에서 확인하세요.
Zebra: 배출 보정 ~TA는 ±120단계이며 600DPI는 1단계가 2도트입니다. 세우테크는 모델별 명령 확인 전 고급 배출 보정을 제공하지 않습니다.
설정 저장은 config.ini에만 반영되며 실제 장비 동작을 증명하지 않습니다. 명령 적용과 첫 장·다음 장의 시작 위치, 추가 배출, 절취·커터, 스캔을 실제 프린터로 확인하세요.


자동 기본 배치 수정 2026.10.20.01
40×20mm의 상품명·상품 코드·LOT·수량은 실제 글자 크기로 측정해 배치합니다. 짧은 항목은 두 열로 배치하며 8pt부터 최소 5pt까지 맞춥니다. 전체 값·선행 0·바코드 필수 여백을 보존합니다. 최소 크기로도 맞지 않으면 용지나 저장 도안을 조정합니다.
출력 관리의 자동 기본 배치 사용 → 현재 도안 미리보기로 첫 대상의 용지·방향·위치 보정을 확인합니다. 닫기 또는 Esc로 돌아갑니다. 미리보기는 DB·기본 인쇄 데이터·설정을 변경하거나 프린터로 보내지 않습니다. 실제 첫 장의 글자 크기·스캔은 장비에서 확인합니다.
