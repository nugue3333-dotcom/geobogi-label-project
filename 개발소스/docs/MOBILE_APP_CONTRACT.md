# 채움LAB 모바일 앱 공통 규격

Android와 iOS 앱은 PC 라벨 디자이너의 보조 출력기가 아니라, 현장에서 템플릿을 편집하고 데이터를 선택해 무선 LAN으로 출력할 수 있는 동일 제품군으로 동작한다.

## 핵심 작업 흐름

1. 새 빈 라벨을 만들거나 PC에서 저장한 템플릿을 연다.
2. 라벨의 가로, 세로와 DPI를 확인한다.
3. 텍스트, 1D 바코드, QR 코드, 선, 박스를 추가하고 이동, 크기, 회전을 편집한다.
4. CSV 데이터를 불러오면 모든 열을 대상으로 검색하고 한 행을 선택한다.
5. 선택 행의 값을 `{{열 이름}}` 형식의 개체에 적용한다.
6. 출력 매수와 프린터 설정을 확인한 뒤 무선 LAN으로 전송한다.
7. 전송 성공과 실제 라벨 출력 성공은 구분해서 안내한다.

## 템플릿 파일

- 기본 템플릿은 항상 `elements: []`인 빈 상태다.
- JSON 파일의 `version`은 현재 `1`이다.
- 라벨 크기는 `label.width_mm`, `label.height_mm`에 저장하며 앱의 고정 기본값으로 덮어쓰지 않는다.
- 바코드와 DB 값은 숫자로 변환하지 않고 문자열로 보존한다.
- 개체 공통 좌표는 mm 단위다.

```json
{
  "version": 1,
  "label": {
    "width_mm": 50,
    "height_mm": 40
  },
  "elements": [
    {
      "id": "element-1",
      "type": "text",
      "text": "{{품목명}}",
      "x": 2,
      "y": 2,
      "width": 30,
      "height": 6,
      "rotation": 0,
      "font_size": 12,
      "align": "left"
    }
  ]
}
```

지원 개체 유형은 `text`, `barcode`, `qrcode`, `line`, `box`다. 회전은 `0`, `90`, `180`, `270`만 허용한다.

## 데이터 소스

- CSV 첫 행을 열 이름으로 사용한다.
- 검색은 품목명만이 아니라 모든 열의 표시 문자열을 대상으로 한다.
- 검색 결과에서 사용자가 선택한 한 행만 현재 미리보기와 출력에 적용한다.
- 앞자리 0, 원화 기호, 한글은 원문 문자열 그대로 유지한다.
- 템플릿에 없는 열은 빈 값으로 조용히 바꾸지 않고 사용자에게 표시한다.

## 프린터 설정

- 연결: 무선 LAN 전용, IP와 포트 기본값 `9100`
- 브랜드: TSC, BIXOLON, Zebra, SEWOO
- 해상도: 203, 300, 600 DPI
- 용지: 갭, 블랙마크, 연속 용지
- 인쇄 방식: 감열, 열전사
- 인쇄 후 작업: 제조사별 확인된 범위에서 뜯어내기, 커터, 필러
- 출력 매수: 1 이상

제조사별로 공식 확인되지 않은 명령은 지원한다고 표시하지 않는다. 지원하지 않는 조합은 설정 저장 또는 출력 전에 명확히 차단한다.

| 제조사 | 명령/인코딩 | 뜯어내기 | 커터 | 필러 |
| --- | --- | --- | --- | --- |
| BIXOLON | SLCS / CP949 | 허용 | 허용 | 차단 |
| TSC | TSPL / UTF-8 | 허용 | 허용 | 허용 |
| Zebra | ZPL / UTF-8 | 허용 | 허용 | 허용 |
| SEWOO | ZPL / UTF-8 | 허용 | 차단 | 차단 |

세우테크는 공식 검증 모델 목록이 마련되기 전까지 뜯어내기만 허용한다. 화면에서 모델명 입력을 요구하지 않더라도 내부 호환성 제한은 유지한다.

## 전송 상태와 오류 처리

- `전송 완료`는 프린터 소켓으로 명령 전송을 마쳤다는 뜻이다.
- 실제 용지 배출과 위치, 크기, 농도는 사용자가 확인해야 한다.
- 연결 또는 전송 실패 후 진행 상태를 반드시 해제해 같은 화면에서 바로 재시도할 수 있어야 한다.
- 중복 탭으로 같은 작업이 두 번 전송되지 않도록 전송 중에는 출력 버튼을 잠근다.
- 정상일 때는 결과 메시지를 한 번만 표시하고, 오류일 때만 원인과 재시도 방법을 표시한다.

## 플랫폼별 배포 기준

- Android: 설치 가능한 APK와 빌드에 사용한 소스를 함께 제공한다.
- iOS: Windows에서는 서명된 IPA를 만들 수 없으므로 Xcode에서 열 수 있는 전체 프로젝트를 제공하고, macOS에서 빌드와 실제 기기 검증을 완료한 뒤 배포한다.
- 실제 프린터 장비 검증은 브랜드, 모델, DPI, 용지, 인쇄 후 작업별 체크리스트로 별도 기록한다.
