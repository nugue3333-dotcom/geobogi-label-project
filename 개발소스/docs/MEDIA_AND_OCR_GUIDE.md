# 용지 설정과 도안 인식 · 2026.10.21.02

## 용지 규격과 도안 방향

1. 프린터 설정에서 실제 라벨 폭·길이를 mm로 입력합니다. 50.5 × 30.25처럼 소수점 규격도 저장합니다.
2. 세로 / 가로 / 세로 180도 / 가로 180도를 선택합니다. 가로 방향은 전체 작업면을 반시계 90도 회전합니다.
3. 좌우·상하 보정은 인쇄 내용의 위치를 움직입니다. 양수는 오른쪽·아래쪽이며 라벨 밖으로 나가면 인쇄를 막습니다.
4. 용지 보정 영역의 용지 감지 보정과 절단·배출 위치 보정에 필요한 값만 입력합니다.
5. 도안 적용 전에 현재 용지와 규격·방향 차이를 확인합니다. 이미지 인식은 원본과 전체 인식 값 확인을 거칩니다.
6. 인쇄 방향을 바꿔도 이미 잘못 인식된 문자열은 복구되지 않습니다. 원본을 다시 적용하고 영문·한글·숫자·앞자리 0을 대조합니다.
7. BarTender 파일(.btw)은 확장자만 PNG로 바꿔도 이미지가 되지 않습니다. 원본 프로그램에서 PNG/PDF로 내보냅니다.

## 제조사별 용지 배출 보정

좌우·상하 보정은 인쇄 내용 위치를 바꿉니다. 센서·절취선 보정은 용지 이송 동작을, 공급 보정은 출력 후 위치를 바꿉니다. 실물 용지 이동은 미리보기에 나타나지 않습니다.

| 제조사 | 센서·절취선 / 추가 이송 | 공급·절취 위치 |
|---|---|---|
| BIXOLON SLCS | 용지 감지 보정. 앱 입력은 ±12mm와 ±100도트 중 좁은 범위(0.1mm 단위 절사)로 제한. | 절단·배출 위치 보정. 203 DPI ±12mm / 300 DPI ±8.4mm / 600 DPI ±4.2mm. |
| TSC TSPL | 갭·블랙마크 GAP/BLINE 추가 이송 0~용지 길이. | OFFSET ±25.4mm. |
| Zebra ZPL | 같은 방식의 사용자 센서 오프셋은 이 화면에서 제공하지 않음. | ~TA ±120단계. 600 DPI는 1단계당 2도트. |
| SEWOO | 모델별 확인 필요. | 승인된 모델별 명령 확인 전 미제공. |

### ‘현재 프린터 설정 사용’과 0mm

- BIXOLON: 용지 감지의 ‘별도 보정 없음’은 SL 명령의 p4와 SF1을 생략합니다. 용지 종류·규격은 계속 전송하므로 기존 마크·절취선 거리를 유지하는 모드가 아닙니다. 직접 입력하는 감지·정지 보정은 위 표의 범위를 적용합니다.
- TSC: 현재 설정 사용은 GAP/BLINE 명령 전체를 생략해 프린터에 저장된 용지 종류와 추가 이송을 함께 유지합니다. 직접 0mm를 입력하면 선택한 갭/블랙마크 종류와 추가 이송 0을 명시합니다. OFFSET 공급 보정은 별도로 처리합니다.
- BIXOLON TA는 프린터에 영구 저장되므로 기존 설정을 기록해야 합니다. ‘현재 설정 사용’은 이전 TA 값의 복원 명령이 아닙니다.
- 설정 저장은 config.ini만 변경합니다. 실제 적용은 출력 작업의 명령에 포함되며, 실제 이동량·커터 동작·다음 라벨 시작점은 프린터 모델과 펌웨어에서 별도로 확인해야 합니다.

현재 테스트는 명령 생성과 설정 저장 검증입니다. 실물 프린터에서 배출 동작을 확인한 기록은 없으며 모델 호환성 승인을 의미하지 않습니다.

## 자동 기본 배치

40×20mm에서는 상품명·상품 코드·LOT·수량의 실제 글자 크기를 측정합니다. 짧은 항목은 두 열로 배치하고 최소 5pt까지 조절합니다. 값·앞자리 0·바코드 여백을 보존하고 들어가지 않으면 용지나 저장 도안을 조정합니다.

## 간소화된 프린터 설정 (2026.10.21.02)

용지 크기·방향 아래에서 용지 감지 보정과 절단·배출 위치 보정을 직접 입력합니다. 용지 감지 보정의 ‘별도 보정 없음’은 용지의 기본 감지 기준을 사용합니다. 절단·배출 위치의 ‘현재 프린터 설정 사용’은 정지 보정 명령을 생략합니다. 0은 기본 위치로 설정합니다. 저장한 값은 같은 폴더의 프로그램에서 다음 인쇄부터 적용됩니다. 사용자 펌웨어 확장 및 본체 설정 유지 버튼은 제거했습니다. 자동 배치용 바코드 설정은 필요할 때만 펼칩니다. RAW 출력이므로 Windows 드라이버의 범위를 자동 조회하지 않습니다. 빅솔론 ±12mm는 사용자 요청 상한이며, 고해상도에서는 공식 100도트 범위가 우선합니다. 기존 범위 초과 값은 자동으로 잘라 적용하지 않고 저장·출력을 차단합니다.
