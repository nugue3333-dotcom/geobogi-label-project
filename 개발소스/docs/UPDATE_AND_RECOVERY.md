# 고객 업데이트·PC 교체·복구

## 매일 시작

처음 설치할 때는 배포 폴더 전체를 복사한 뒤 `처음실행_점검.cmd`를 실행합니다. 평소에는 **시작하기.cmd** 한 개를 실행하면 라벨 출력 관리가 열립니다. 화면의 도구 메뉴에서 프린터 설정과 디자이너로 이동합니다. `tools` 안의 보조 EXE는 고객이 직접 실행할 대상이 아닙니다.

## 업데이트

1. 현재 프로그램을 닫습니다. 파일 → 고객 데이터 백업에서 만든 ZIP과 기존 설치 폴더를 별도로 보관합니다.
2. 새 배포본을 **다른 폴더**에 풉니다. 기존 운영 폴더·엑셀·config.ini를 새 기본값으로 덮어쓰지 않습니다.
3. 새 폴더에서 `처음실행_점검.cmd`를 실행하고 파일 → 고객 데이터 복원으로 백업을 가져옵니다. 복원 전 현재 데이터는 pre-restore 백업으로 보관됩니다.
4. 버전, 프린터, 용지 규격, DB 파일·시트·열, 현재 도안·미리보기·매수를 확인합니다. 원본 상품 엑셀과 별도 보관 도안·글꼴은 함께 옮겨 다시 연결합니다.
5. `01_output_check.cmd`는 인쇄 파일 생성만 확인합니다. 실제 프린터에서 첫 장을 내보내고 스캔 확인한 뒤 업무에 사용합니다.

고객 백업에는 값 생성 발급·재인쇄 기록인 `out/value_jobs/ledger.json`도 포함합니다. 다른 로그와 지원 ZIP은 포함하지 않습니다. 현재 PC보다 오래된 발급 번호, 사라진 작업 기록, 손상된 기록 또는 발급 중 잠금이 있으면 안전을 위해 복원이 중단됩니다. 최신 백업과 실제 사용 번호를 확인한 뒤 지원 점검을 받으세요. 기존 기록 파일을 삭제하여 복원을 강제로 통과시키지 않습니다.

기존 데이터 폴더가 있으면 `%LOCALAPPDATA%\ChaeumLAB\LabelPrint`도 백업합니다. 오래된 `%LOCALAPPDATA%\GeobogiLabel` 데이터는 첫 실행 시 새 경로로 복사될 수 있으므로 새 PC에서 경로와 내용이 맞는지 확인합니다.

## 문제가 있으면

새 버전 사용을 멈추고 기존 폴더·백업을 보관한 상태에서 복구합니다. 이미 프린터가 수신한 명령은 취소됐다고 가정하지 말고 출력물을 확인합니다. 일련번호를 발급한 뒤에는 이전 버전의 오래된 기록에서 계속 발급하지 않습니다. 최신 발급 기록과 실제 사용 번호를 대조한 뒤 재개 또는 재인쇄를 명시적으로 선택합니다. 도움말 → 지원 패키지 생성으로 점검 결과를 준비하고 승인된 지원 채널에 문의합니다.

지원 기간·비용·응답 시간은 [유료 조건 승인대기표](PAID_SUPPORT_TERMS_DRAFT.md)의 승인 전에는 약속하지 않습니다.
