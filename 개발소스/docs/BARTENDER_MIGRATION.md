# BarTender 도안을 채움랩으로 옮길 때

2026-10-01 확인: 파일명만 `.png`로 바꿔서는 변환되지 않습니다. 실제 BarTender 원본으로 확인된 `유진디스컴.png` 사례와 다른 프로그램의 공식 연동 방법은 [도안 가져오기 검토 보고서](LABEL_FILE_IMPORT_REVIEW_2026-10-01.md)를 참고하세요.

새 도안은 `.cllabel`, 이동 프로젝트는 `.clproject`로 저장합니다. 기존 `.gblabel`·`.gbproject`와 라벨 템플릿 `.json`도 열 수 있습니다. BarTender의 `.btw` 파일을 직접 열거나 개체·수식·데이터 연결·프린터 설정을 자동 변환하지 않습니다.

1. BarTender에서 원본 도안의 **가로·세로(mm), 프린터 DPI, 글꼴, 바코드 종류와 값 생성 규칙**을 기록합니다.
2. 원본 도안을 PNG 이미지로 준비합니다. 이미지가 없으면 원본 화면을 캡처할 수 있지만, 화질에 따라 인식 정확도가 떨어질 수 있습니다.
3. 채움랩에서 **도안 불러오기 → 도안 적용 → 인식 값 검토**를 순서대로 실행합니다. 인식된 텍스트·바코드를 원본과 비교해 잘못된 값과 임시 값을 수정한 뒤 **전체 값 확인**으로 한 번에 확정합니다.
4. 상품 엑셀을 연결하고 각 개체의 열을 다시 지정합니다. 빈 값·앞자리 0·긴 상품명·필수 필드를 점검합니다.
5. 라벨 크기, 바코드 여백, 모듈 크기, 인쇄 방향과 프린터 설정을 대조합니다.
6. 인쇄파일 미리보기와 **첫 장 실물**을 원본 라벨과 나란히 비교합니다. 1D와 2D 코드는 각각 실제 스캐너로 읽어 값을 확인합니다.

도안을 다른 PC로 옮길 때는 **파일 → 이동 프로젝트 내보내기**에서 `.clproject`를 만듭니다. 이미지와 글꼴 이름은 포함하지만 엑셀 원본, 글꼴 파일, 프린터 설정은 포함하지 않습니다. 원본 엑셀을 별도로 옮긴 뒤 가져온 PC에서 데이터와 프린터를 다시 연결하고 첫 장을 확인하세요. 구형 도안은 일반 저장 시 기존 파일을 유지하며 새 `.cllabel`로 바꾸려면 다른 이름으로 저장합니다.

## 이전 가능 범위부터 확인

| 원본 항목 | 처리 방식 | 고객 확인 |
| --- | --- | --- |
| 고정 배경·로고 | 실제 PNG/JPG로 내보내 참고 이미지 사용 | 크기·방향·이미지 품질 |
| 고정 문자·일반 바코드 | 인식 후보 검토 또는 직접 재작성 | 원문·앞자리 0·바코드 종류 |
| DB 값·GS1 AI | 상품 엑셀 열과 AI를 다시 연결 | 필수 조합·길이·체크숫자·스캔값 |
| 일련번호·날짜·부분 추출 | 지원하는 값 생성 규칙으로 재구성 | 증가·자리수·복사·재개·재인쇄 |
| 스크립트·다중 DB·조건식 | 원본 규칙을 접수해 개별 검토 | 미지원·수동 작업 범위를 먼저 합의 |
| 프린터 설정·글꼴 | 해당 PC와 장비에서 다시 설정 | DPI·센서·용지·실물 첫 장 |

PNG는 단일 이미지입니다. 편집 개체나 DB 연결이 그대로 복원되는 방식이 아닙니다. **손실 없는 자동 변환·완전 호환을 약속하지 않습니다.** 다른 라벨 프로그램도 같은 접수·재작성·대조 절차로 검토합니다.

전환 결과는 [도안 이전 대조표](TEMPLATE_MIGRATION_CHECKLIST.md)에 기록합니다. 실제 고객 도안 검수와 고객 승인 전에는 이전 완료로 표시하지 않습니다. 지원 비용과 포함 도안 수는 [유료 조건 승인대기표](PAID_SUPPORT_TERMS_DRAFT.md)에 따로 확정합니다.
