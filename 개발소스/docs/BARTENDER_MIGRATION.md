# BarTender 도안을 채움랩으로 옮길 때

2026-10-01 확인: 파일명만 `.png`로 바꿔서는 변환되지 않습니다. 실제 BarTender 원본으로 확인된 `유진디스컴.png` 사례와 다른 프로그램의 공식 연동 방법은 [도안 가져오기 검토 보고서](LABEL_FILE_IMPORT_REVIEW_2026-10-01.md)를 참고하세요.

채움랩 라벨 디자이너는 `.gblabel`, 라벨 템플릿 `.json`, 이동용 `.gbproject`를 사용합니다. BarTender의 `.btw` 파일을 직접 열거나 객체·수식·데이터 연결·프린터 설정을 자동 변환하지 않습니다.

1. BarTender에서 원본 도안의 **가로·세로(mm), 프린터 DPI, 글꼴, 바코드 종류와 값 생성 규칙**을 기록합니다.
2. 원본 도안을 PNG 이미지로 준비합니다. 이미지가 없으면 원본 화면을 캡처할 수 있지만, 화질에 따라 인식 정확도가 떨어질 수 있습니다.
3. 채움랩에서 **도안 불러오기 → 도안 적용 → 인식 값 검토**를 순서대로 실행합니다. 인식된 텍스트·바코드를 원본과 비교해 잘못된 값과 임시 값을 수정한 뒤 **전체 값 확인**으로 한 번에 확정합니다.
4. 상품 엑셀을 연결하고 각 개체의 열을 다시 지정합니다. 빈 값·앞자리 0·긴 상품명·필수 필드를 점검합니다.
5. 라벨 크기, 바코드 여백, 모듈 크기, 인쇄 방향과 프린터 설정을 대조합니다.
6. 인쇄파일 미리보기와 **첫 장 실물**을 원본 라벨과 나란히 비교합니다. 1D와 2D 코드는 각각 실제 스캐너로 읽어 값을 확인합니다.

도안을 다른 PC로 옮길 때는 **편집·이동 → 이동용 프로젝트 내보내기**를 사용합니다. 이미지와 글꼴 이름은 포함하지만 엑셀 원본, 글꼴 파일, 프린터 설정은 포함하지 않습니다. 가져온 PC에서 데이터와 프린터를 다시 연결하고 첫 장을 확인하세요.
