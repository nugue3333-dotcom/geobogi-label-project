## 확인이 남은 범위

- LibreOffice와 Microsoft Word 렌더러가 없어 DOCX를 이미지로 렌더링해 페이지별 시각 검수하지 못했습니다. DOCX 구조·표 행 분할·파일 해시는 자동 검사했습니다.
- 고객 배포본의 실행 전 점검은 격리된 임시 폴더에서 출력 엔진 dry-run까지 완료했습니다. 실제 프린터 전송, 라벨 배출, 스캐너 판독은 하지 않았으며, 현장 프린터에서 1장 출력과 값 스캔이 필요합니다.
- 이번 릴리스는 로컬 개발소스와 고객 배포 폴더·ZIP에 반영했습니다. GitHub 원격 저장소에는 업로드하지 않았습니다.
