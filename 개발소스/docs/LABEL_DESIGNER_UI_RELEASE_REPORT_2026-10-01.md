PDF 작업 시작 기록용 Node 도구는 이 PC의 ncrypto::CSPRNG(nullptr, 0) 환경 오류로 시작하지 못했다. Python 기반 매뉴얼 생성·렌더링·검증과 EXE 빌드는 완료했다.

## 제한과 현장 확인

- 설치된 BarTender 2016 R2의 COM 실행은 **0x80080005**로 실패했다. 복원 원본의 실제 열기·이미지 내보내기는 완료하지 못했다. 도안을 만든 버전에서 실제 PNG 내보내기가 필요하다.
- 상용 원본 직접 변환기와 PDF/SVG 가져오기는 이번 배포에 구현하지 않았다. 개발안과 제한은 가져오기 보고서에 기록했다.
- 실제 출력·스캔은 하지 않았다. 고객 용지 크기·DPI·DB 열·바코드 종류를 지정하고 첫 장 출력·1D/2D 스캔을 확인해야 한다.
- 전체 값 확인은 사용자의 원본 대조를 빠르게 승인한다. OCR 정확성을 자동 보증하지 않는다.

## 업데이트와 되돌리기

새 배포 폴더 전체를 사용한다. 기존 고객 설정·엑셀·저장 도안은 백업하고 유지한다. 문제가 생기면 보존한 `채움랩_라벨출력_고객용_20260930_02` 프로그램으로 되돌리되, 고객 데이터를 데모 데이터로 덮어쓰지 않는다.
