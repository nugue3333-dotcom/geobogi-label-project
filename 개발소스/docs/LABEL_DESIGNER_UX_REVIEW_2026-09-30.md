# 라벨디자이너 사용자 관점 평가와 BarTender 비교

작성일: 2026-09-30 · 평가 대상: 채움랩 고객배포 **2026.09.30.01**

> 이 문서는 2026.09.30.01의 평가 기록이다. 후속 수정과 새 고객 배포 검증 결과는 [구현·배포 보고서](LABEL_DESIGNER_IMPLEMENTATION_RELEASE_REPORT_2026-09-30.md)에 기록한다.

## 1. 결론

**쓸 이유는 있다. 다만 현재 상태에서 모든 BarTender 사용자의 교체를 권하기는 어렵다.**

엑셀 상품 목록을 사용하고, 몇 가지 라벨을 반복 출력하며, 프린터 설정과 도안 준비까지 지원받고 싶은 소규모 매장·작업장은 채움랩이 집중할 고객이다. 이 고객이 구매할 이유는 “프로그램의 기능이 더 많다”보다 **자기 장비와 업무에 맞게 준비되어 있고, 직원이 적은 단계로 정확하게 출력할 수 있다**는 것이다.

현재도 실제 열 연결, 데이터 검색·선택, 개체 편집, 도안 이미지 분석, 한국어 글꼴 출력, 출력 매수 확인, 오류 후 재시도, 고객 점검·백업 도구가 있다. 그러나 첫 실행 안내, 반복 작업에 맞춘 화면, 편집 실수 복구, 도안 이동성에서 이 장점이 충분히 드러나지 않는다. “BarTender보다 더 쉽다”는 주장을 입증하는 실제 초보 사용자 비교 결과도 아직 없다.

복잡한 규격 라벨, 다양한 외부 시스템, 여러 현장의 승인·권한·이력 관리, 많은 기존 `.btw` 도안이 필요한 고객에게는 현재 BarTender를 유지하는 쪽이 합리적이다. 이 판단은 현재 구현 범위와 공식 제품 자료를 비교한 제품 평가이며, 두 제품의 인쇄 속도나 스캔 품질을 측정한 결과가 아니다.

BarTender는 상위 제품에서 데이터 연결, 인쇄 시 입력 폼, 시스템 연동, 권한·이력 관리 등을 제공한다. 엑셀·바코드·입력 폼 자체를 채움랩만의 기능으로 소개하면 안 된다. [공식 기능·제품 비교](https://www.bartendersoftware.com/product/pricing), [공식 입력 폼 안내](https://support.seagullsoftware.com/hc/en-us/articles/214448067-Data-entry-forms-Designing-a-data-entry-form-Video-5-51)

UltraLite에는 스프레드시트·데이터베이스 등 외부 데이터에서의 인쇄 제한이 안내되어 있다. 이 제품과 데이터 연결이 가능한 상위 제품의 비교를 구분해야 한다. [UltraLite 공식 안내](https://www.bartendersoftware.com/product/on-premises/ultralite)

가격 우위를 확정하지 않았다. 국내 견적, 라이선스 범위, 유지보수와 설치 지원 조건, 채움랩 판매 조건을 같은 기준으로 비교해야 한다. “가장 저렴하다”, “모든 프린터와 호환된다”, “지원이 무제한이다”는 표현은 현재 근거가 없다.

## 3. 현재 제품에서 유지할 장점

- **실제 엑셀 열을 개체에 연결:** 정해진 내부 필드만 보여주는 방식이 아니며, 실제 열 선택과 미리보기·검색·행 선택이 이미 있다.
- **한국어 글꼴과 다양한 개체:** 텍스트·여러 줄·1D·2D·이미지·선·박스·표·회전 기능이 있다. DataMatrix·PDF417 등도 디자이너 코드의 비트맵 출력 범위에 포함된다. QR만 가능한 제품으로 평가하지 않았다.
- **명시적인 출력 절차:** 출력 가능 내용과 이미지 파일을 점검하고, 실제 인쇄 전에 매수를 확인한다. 명령을 준비한 뒤 전송하며, 처리한 전송 실패에는 재시도 상태가 있다.
- **저장 보호:** 다른 파일 열기·초기화·종료 전에 미저장 변경 확인이 있으며, JSON 원자적 저장과 기본 템플릿 복구가 있다. 저장 안전장치가 전혀 없는 제품은 아니다.
- **설치·지원 기반:** 프린터 설정, 고객 환경 점검, 배포 manifest, 백업·복원 도구가 있다. 이 도구를 고객의 한 작업 흐름으로 연결하는 것이 중요하다.
- **일관된 디자인 기반:** 색상·간격·글꼴 토큰과 브랜드 로고가 이미 있다. 현재의 흰색·짙은 청록색 계열은 업무용 제품에 적합하며, 색상이나 장식을 늘릴 필요는 없다.

## 5. 권장 화면 구조

현재 스택과 디자인 토큰을 활용해 화면의 역할부터 정리하는 것이 적절하다. 프레임워크 교체를 선행 조건으로 두지 않는다.

```text
상단: 새 라벨 · 열기 · 저장       현재 파일명/미저장       프린터 · 인쇄

디자인 작업
┌────────────┬───────────────────────────┬────────────────────┐
│ 작은 도구  │ 라벨 캔버스               │ 개체 속성 / 데이터 │
│ + 텍스트   │ 선택 · 정렬선 · 줌        │ 선택 개체에 맞춘   │
│ + 바코드   │ 경계/누락 경고            │ 속성만 표시        │
│ + 이미지   │                           │                    │
└────────────┴───────────────────────────┴────────────────────┘
하단: 라벨(mm) · DPI · 프린터/연결 방식 · 저장 상태 · 출력 확인 상태

출력 작업
라벨 선택 → 상품 검색/스캔 → 대상·매수 확인 → 미리보기 → 전송 → 실물 확인
```

화면 개선의 기준은 장식이 아니라 **캔버스의 넓이, 명령의 찾기 쉬움, 현재 상태와 다음 행동의 명확성**이다. 확대율 100%는 실물 크기로 검증되는 경우에만 그렇게 표시하고, 단순히 창에 맞춘 크기는 `화면 맞춤`으로 구분한다.

### 추가 확인이 필요한 것

실제 프린터의 배출·위치·스캔 품질, 소규모 고객의 학습 시간, 저사양 PC의 OCR·큰 엑셀 응답성, 다른 DPI·배율과 화면읽기 접근성, 고객 PC에서의 업데이트·복원 경험은 별도 확인이 필요하다. 기존 단위 테스트의 통과 개수만으로 이러한 결과를 입증하지 못한다.

**최종 제안:** 판매 초점을 “BarTender를 전부 대체하는 디자이너”에서 **“엑셀 상품을 현장 장비에서 쉽게 반복 출력하고 설치·도안·운영 지원을 함께 받는 패키지”**로 구체화한다. 그 약속을 증명할 첫 작업 안내·정확도·복구·반복 출력 흐름을 우선 완성한다.
