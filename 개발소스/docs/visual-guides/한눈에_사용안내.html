01실물 규격부터 맞춥니다

프린터 연결, 상품 엑셀, 도안을 차례로 확인합니다.

상품 엑셀 첫 행 예시
바코드품명
00123456예시 상품

첫 행은 열 이름입니다. 바코드 열이 있어야 하며, 앞자리 0이 있는 값은 Excel에서 문자로 저장합니다.

  1. 프린터설정.exe에서 연결·규격 저장

    LAN은 IP·포트, USB/Windows 드라이버 연결은 Windows 프린터 이름을 확인합니다.

    실제 라벨 폭·높이(mm), DPI, 용지 유형·간격을 입력하고 설정 점검 후 저장합니다. 저장 후 라벨출력관리.exe를 다시 엽니다.

  2. 라벨출력관리.exe에서 상품 엑셀 연결

    DB 파일 > DB 연결에서 사용할 상품 엑셀을 선택합니다. 불러온 바코드와 상품 값을 원본 엑셀과 대조합니다.

  3. 라벨디자이너.exe에서 도안 확인

    예제로 시작 또는 새 라벨로 도안을 만들고 .gblabel로 저장합니다.

    사진·도안을 불러왔다면 인식 값 검토에서 원본과 글자·바코드를 비교하고 수정·확정합니다.

  4. 파일 확인 후 한 항목·1매로 첫 출력

    출력할 항목 하나를 체크하고 생성된 인쇄파일을 확인합니다. 실제 인쇄 시 인쇄 매수 선택에서 대상과 1매를 확인합니다.

    나온 라벨의 내용·위치와 바코드 스캔 결과까지 확인합니다.

인쇄파일 생성과 실제 출력은 별도 단계입니다

인쇄파일 생성은 프린터로 보내지 않습니다. 전송 완료 표시 후에도 실제 라벨 배출과 바코드 판독을 확인합니다.

02매일 사용하는 네 장면

라벨출력관리.exe에서 조회, 선택, 매수 확인, 실물 확인 순서로 진행합니다.

  1. 01입력칸을 선택하고 스캔

    상단 DB 상품조회 입력칸에 커서를 둡니다. 스캔 후 Enter가 입력되면 같은 바코드를 찾습니다.

    찾을 수 없다는 안내가 나오면 연결한 DB와 바코드 값을 확인합니다.

  2. 02중복 결과에서 필요한 행 선택

    같은 바코드가 여러 건이면 중복 DB 항목 선택 창에서 원하는 행을 체크하고 확인합니다.

    확인한 행만 인쇄 데이터에 체크됩니다. 이전에 체크했던 다른 행은 선택에서 제외됩니다.

  3. 03인쇄 대상·매수를 확인

    항목을 체크하고 출력 > 인쇄를 누릅니다. 인쇄 매수 선택에서 대상과 매수를 확인합니다.

    선택한 각 항목에 같은 매수가 적용됩니다. 취소하면 프린터로 보내지 않습니다.

  4. 04실물 라벨과 스캔 결과 확인

    라벨이 실제로 나왔는지, 내용과 위치가 맞는지 확인하고 바코드를 다시 스캔합니다.

    전송 완료는 명령을 보냈다는 뜻입니다. 실제 출력·판독 확인이 필요합니다.

화면과 동작을 단순화한 설명 그림입니다. 그림 속 바코드는 스캔용이 아닙니다.

선택한 행만 인쇄됩니다

선택한 행이 없으면 인쇄가 차단됩니다. 전체를 출력하려면 전체 선택 후 인쇄 매수 선택에서 대상과 매수를 확인합니다. 첫 테스트는 한 항목·1매로 진행합니다.

03보내기 전, 여섯 가지 확인

실제 값을 직접 확인한 뒤 표시합니다. 첫 출력은 한 항목·1매로 시험합니다.

수동 확인 항목 6개

직접 확인한 항목 수를 표시합니다.

표시는 수동 확인 기록입니다. 장비 상태나 출력 성공을 자동으로 판정하지 않습니다. 화면 안내의 체크 표시는 다시 열면 초기화됩니다. PDF의 체크칸은 인쇄 후 직접 표시합니다.

마지막 확인은 실제 나온 라벨입니다

라벨 내용·위치와 바코드 판독을 확인한 뒤 반복 출력합니다. 인쇄 매수 선택을 취소하면 명령은 전송되지 않습니다.

04설치에서 반복 출력까지

파일 준비, 설정, 데이터, 도안, 파일 확인, 실물 출력 순서입니다.

  1. 1

    패키지 폴더 전체를 보관

    압축을 푼 폴더 전체를 한 위치에 둡니다. 실행 파일과 config.ini, barcode_db.xlsx, print_queue.xlsx 이름을 유지합니다.

  2. 2

    프린터 연결·라벨 규격 저장

    프린터설정.exe에서 연결 대상과 실제 mm·DPI·용지를 확인하고 설정 점검 후 저장합니다. 출력 관리 프로그램을 다시 엽니다.

  3. 3

    상품 엑셀 연결·원본 확인

    라벨출력관리.exe의 DB 파일 > DB 연결을 사용합니다. 첫 행의 바코드 열과 앞자리 0, 불러온 값을 확인합니다.

  4. 4

    도안 저장·인식 값 확정

    라벨디자이너.exe에서 도안을 확인하고 .gblabel로 저장합니다. 도안 인식 값은 원본과 대조한 뒤 수정·확정합니다.

  5. 5

    프린터로 보내기 전에 파일 확인

    인쇄파일 생성으로 생성 결과와 도안 내용을 확인합니다. 이 단계는 프린터로 전송하지 않습니다.

  6. 6

    한 항목·1매로 실제 출력

    항목 하나를 체크하고 인쇄를 누릅니다. 인쇄 매수 선택에서 대상과 1매를 확인한 뒤 라벨 배출·내용·위치·바코드 스캔을 확인합니다.

  7. 7

    확인 후 반복 출력·백업

    필요한 행과 매수를 지정해 반복 출력합니다. 전송이 중단되었다면 실제 나온 라벨을 먼저 확인하고 재전송 대상을 직접 고릅니다. PC 이전 전에는 설정 > 고객 데이터 백업을 실행합니다.

문제가 있을 때 확인할 곳

프린터가 반응하지 않음

LAN은 IP·포트와 같은 네트워크인지 확인합니다. USB/Windows 드라이버 연결은 설정한 Windows 프린터 이름을 확인합니다.

내용이 원본과 다름

연결 DB, 선택한 행, 바코드 앞자리 0, 인식 확정 값을 확인합니다. 이전 값이 나오면 인쇄 데이터를 저장한 뒤 다시 확인합니다.

바코드가 읽히지 않음

실제 라벨 크기와 DPI가 설정과 맞는지 확인합니다. 실제 나온 바코드의 크기를 확인하고 다시 스캔합니다.

배포 폴더에 포함된 경우만 사용하는 보조 파일: 처음실행_점검.cmd는 최초 점검, 01_output_check.cmd는 전송 없는 파일 생성 점검, 고객데이터_백업.cmd·고객데이터_복원.cmd는 백업·복원용입니다. 상세 설명은 사용안내.txt, 설치_및_사용_메뉴얼.txt를 확인합니다.
