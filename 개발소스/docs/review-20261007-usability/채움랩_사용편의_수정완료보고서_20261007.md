# 채움랩 사용편의 수정 완료 보고서

버전 2026.10.07.01 · 빌드 suite_20261007_01 · 2026-10-07 KST

## 1. 완료 결과

승인하신 사용편의 개선계획의 네 항목을 실제 소스에 반영했습니다. 고객 매뉴얼은 변경된 프로그램의 실제 실행 화면으로 다시 만들었습니다. 실행파일 6종 빌드와 새 고객배포본 생성, 실행파일 동작 73개 항목 검증까지 완료됐습니다. 소스·고객 실행폴더·상위 최종폴더·새 고객배포본의 실행파일과 공통 배포 파일이 일치합니다.

- 개체 복사·붙여넣기: Ctrl+C / Ctrl+V / Ctrl+D로 선택 개체를 복사·붙여넣기·복제합니다. 다중 개체, 그림, DB 연결을 보존하며 실행취소를 지원합니다. 글자 입력칸에서는 해당 글자 편집을 우선합니다.
- 개체 도구 아이콘: 텍스트·여러 줄·1D 바코드·2D 코드·그림·박스·선·표의 8개 도구에 아이콘과 이름을 함께 표시합니다. 기존 도구 기능과 채움랩 브랜드 색상을 유지합니다.
- 라벨 규격 통합: 프린터 설정에서 용지 크기를 한 번 저장합니다. 디자이너의 읽기 전용 공통 규격 표시와 출력 관리가 같은 설정을 사용합니다. 용지 설정 바로가기로 변경하며, 열린 프로그램에도 반영합니다. 다른 규격 도안은 유지 또는 공통 규격 적용을 선택합니다. 개체가 영역을 벗어나는 변경은 취소해 기존 도안을 보호합니다.
- 인쇄 매수 상한 제거: 화면과 출력 엔진의 100장·1,000장 임의 상한을 제거했습니다. 양의 정수, 대상 수와 총 매수를 검증합니다. 매수는 프린터 명령에 보존되며, 전송 중단은 작업 경계에서 확인합니다. 전송 중 중단은 아직 보내지 않은 작업을 멈춥니다. 이미 프린터가 받은 작업의 중단이나 실제 배출 중지는 보장하지 않습니다.

## 2. 고객 사용 순서

1. 개체를 선택하고 Ctrl+C로 복사, Ctrl+V로 붙여넣습니다. 같은 도안에 바로 복제할 때는 Ctrl+D를 사용합니다.
2. 왼쪽의 그림 아이콘과 그림 버튼으로 이미지를 넣습니다. 다른 도구도 아이콘 옆 이름으로 선택합니다.
3. 용지 설정을 열어 실제 라벨 가로·세로(mm), DPI와 용지 간격을 저장합니다. 디자이너에서 크기를 다시 입력하지 않습니다.
4. 인쇄할 항목과 양의 정수 매수를 지정합니다. 총 매수를 확인하고 시작합니다. 시작 전 취소는 프린터에 보내지 않습니다.
5. 첫 실제 출력은 한 항목·1매로 진행하고, 라벨 배출·글자 위치·바코드 판독을 확인합니다.

## 5. 실제 장비 확인과 제한

프로그램 내 매수 상한을 제거했어도 프린터 속도·용지 잔량·실제 통신 환경에 따라 완료 시간은 달라집니다. 소프트웨어 전송 완료는 실물 출력 완료를 뜻하지 않습니다.

- 고객 장비에서 실제 라벨 규격을 저장하고 한 항목·1매 출력과 바코드 스캔을 확인해야 합니다.
- 전송 중 중단은 미전송 작업에 적용됩니다. 이미 수신한 프린터 작업은 장비의 취소 기능으로 별도 확인해야 합니다.
- 직접 .btw 변환과 미승인 SEWOO 장비 지원 여부는 이번 변경 범위에서 확대하지 않았습니다.
- 이번 작업에서 GitHub 업로드와 실제 프린터 전송은 수행하지 않았습니다. 실제 고객 전달 상태도 별도 확인 대상입니다. 이 보고서의 프로그램 검증은 물리 출력이나 고객 설치 완료를 증명하지 않습니다.
