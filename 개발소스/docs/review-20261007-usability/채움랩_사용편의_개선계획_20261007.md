### 이번 보고서의 범위

현재 개발소스와 이전 승인 시안·2026-10-06 배포 화면을 비교했습니다. 아래 내용은 수정 제안입니다. 프로그램 코드·설정·실행파일을 변경하지 않았고, 이번 검토에서는 프로그램 테스트·빌드·실물 인쇄를 실행하지 않았습니다.

### 권장 결정

개체 복사·붙여넣기를 추가하고, 왼쪽 8개 개체 도구의 아이콘을 복구합니다. 라벨 크기는 프린터 설정에서 한 번 입력해 공동 적용하는 방식을 권장합니다. 인쇄 매수는 화면과 출력 엔진 전체에서 임의의 100장·1,000장 상한을 제거합니다.

| 요청 | 확인한 현재 상태 | 권장 수정 |
| --- | --- | --- |
| 1. 개체 복사·붙여넣기 | 개체용 Ctrl+C/V와 클립보드 처리 없음 | 단일·다중 개체 복사 및 붙여넣기 |
| 2. 도구 그림 아이콘 | 그림 기능은 있음. 8개 버튼 아이콘 누락 | 아이콘 + 한국어 이름으로 복구 |
| 3. 라벨 크기 중복 입력 | 설정 저장 후 열린 디자이너 크기 미갱신 | 설정에서 한 번 입력·저장 후 함께 적용 |
| 4. 인쇄 매수 상한 | 100장 제한 및 별도 1,000장 제한 존재 | UI·DB·출력·점검 경로의 상한 통일 제거 |

우선순위는 실제 작업을 막는 복사·붙여넣기와 수량 제한, 용지 규격 일치, 아이콘 복구입니다. 구현할 때에는 각 항목의 검증을 함께 끝내고 마지막에 통합 배포와 매뉴얼을 갱신합니다.

## 01  개체 복사·붙여넣기

원인 확인: 기능과 단축키 연결이 없음

### 현재 문제

현재는 Delete, Ctrl+Z/Y, Ctrl+D 등이 연결되어 있지만 개체용 Ctrl+C/V가 없습니다. 캔버스 클릭 시 포커스를 받는 코드가 있으므로, 원인을 단순 포커스 문제로 판단하지 않습니다.

### 사용자가 경험할 동작

개체를 선택하고 Ctrl+C를 누르면 복사 당시 상태를 보관합니다. Ctrl+V를 누르면 새 개체가 생성·선택되고, 반복해서 붙여넣어도 원본이 변하지 않습니다. 다중 선택과 그룹은 개체 사이 간격을 유지합니다.

### 입력란과 개체 조작 구분

상품명·숫자·검색어를 입력하는 동안에는 일반 글자 복사·붙여넣기를 유지합니다. 캔버스나 개체 도구에 초점이 있을 때 개체 단축키를 처리합니다. 기존 Ctrl+D도 입력 중 개체를 복제하지 않도록 함께 보완합니다.

| 키 / 상황 | 수정 후 기준 |
| --- | --- |
| Ctrl+C | 선택 개체 전체를 복사 당시 상태로 보관 |
| Ctrl+V | 새 개체·그룹 ID 생성, 붙여넣은 개체 선택 |
| Ctrl+Z / 다시실행 | 붙여넣기 전체를 한 작업으로 취소·복구 |
| 다중·그룹 개체 | 상대 위치 유지. 가장자리에서 각각 밀려 간격이 바뀌지 않음 |
| 이미지·DB·바코드 | 이미지 참조·DB 열 연결·글꼴·선행 0 보존 |

같은 도안 및 채움랩 도안 간 복사를 대상으로 합니다. 붙여넣을 도안에 이미지 파일 또는 DB 열이 없으면 연결 상태를 명확히 알려야 합니다.

## 02  개체 도구 아이콘 복구

기능을 찾기 쉬운 아이콘 + 이름 구성

### 현재 상태와 해석

현재도 ‘그림’ 버튼으로 이미지 파일을 추가할 수 있습니다. 과거 승인 시안에서는 개체 도구 8개 버튼 모두 이름 앞에 그림 아이콘이 있었고, 현재 구현은 글자만 표시합니다. 요청은 이 도구 아이콘 복구로 해석했습니다.

### 디자인 방향

텍스트·여러 줄·1D 바코드·2D 코드·그림·박스·선·표에 같은 크기와 선 굵기의 아이콘을 배치합니다. 아이콘만으로 바꾸지 않고 한국어 이름을 유지합니다. 채움랩 로고와 화이트·딥블루·라임 브랜드 조합을 이어 사용합니다.

**아이콘 복구 대상:** 텍스트(T), 여러 줄, 1D 바코드, 2D 코드(QR), 그림(산 모양), 박스, 선, 표.

## 03  라벨 크기는 한 번만 입력

권장: 프린터 설정 저장 → 작업 화면과 출력에 공동 적용

### 중복 입력이 생기는 이유

프린터 설정은 config.ini에 규격을 저장하지만 열린 디자이너는 도안의 메모리 치수를 계속 사용합니다. 출력할 때도 도안 치수가 우선 적용됩니다. 그래서 설정에서 크기를 바꿔도 현재 캔버스가 바뀌지 않습니다.

### 일상 작업 흐름

프린터 설정에서 가로·세로를 입력해 저장합니다. 같은 설정 파일을 사용하는 열린 디자이너가 변경을 감지하고, 라벨 규격·캔버스·출력 크기를 함께 갱신합니다. 디자이너의 별도 숫자 입력과 ‘크기 적용’은 ‘현재 규격 표시 + 용지 설정’ 바로가기로 정리합니다.

### 기존 도안 보호

빈 라벨은 바로 반영합니다. 개체가 있는 도안은 원래 개체의 크기·위치를 유지하고, 새 용지 밖으로 나가는 개체가 있으면 미리보기와 적용 취소를 제공합니다. 규격 충돌이 남아 있으면 인쇄 전에 해소하도록 안내합니다. 저장 전 원본 도안 파일은 덮어쓰지 않습니다.

### 다른 규격의 저장 도안

다른 규격 도안을 열 때에는 도안 규격과 현재 용지 규격을 한 번 보여줍니다. ‘도안 규격으로 용지 설정 적용’ 또는 ‘현재 용지 규격 사용’을 선택하게 하고, 숫자를 다시 입력하도록 요구하지 않습니다. 열기 취소도 가능해야 합니다.

| 선택안 | 사용자 효과 / 고려할 점 |
| --- | --- |
| 공통 적용 (권장) | 프린터 설정에서 한 번 입력. 디자인·관리자 출력 규격 일치. 기존 도안 충돌 처리 필요 |
| 프린터 설정에서 삭제 | 화면은 단순해짐. 출력관리의 독립 사용에도 규격이 필요해 별도의 공통 용지 설정 화면이 필요 |

동기화 범위는 같은 배포 폴더의 같은 config.ini를 사용하는 프로그램입니다. 다른 고객·다른 배포 폴더의 설정은 변경하지 않습니다. 설정 저장을 취소하면 작업 화면도 바뀌지 않아야 합니다.

## 04  인쇄 매수 상한 제거

화면·DB·출력 엔진·환경점검을 함께 수정

### 현재 제한의 위치

디자이너와 출력관리의 매수 창은 100장으로 제한합니다. DB 매수와 임시 큐도 100장으로 낮추는 코드가 있습니다. CLI 출력 엔진 역시 100장 초과를 거절하거나 해당 행을 제외합니다. 관리자 데이터 점검과 고객환경점검에는 별도 1,000장 상한이 있습니다.

### 입력 규칙 통일

1 이상의 정수를 입력하도록 통일하고 100·1,000 등의 임의 상한은 제거합니다. 101·1,001·10,000을 입력해도 그 수를 그대로 유지합니다. 0·음수·소수·잘못된 문자는 전송 전에 오류를 표시합니다. 숫자를 조용히 줄이거나 소수를 정수로 잘라 처리하지 않습니다.

### 총매수와 결과 표시

대상 상품 수와 상품별 매수, 총 출력량을 확인창에 정확히 표시합니다. 예: 상품 3건 × 각 500장 = 총 1,500장. 제외되거나 실패한 대상이 있는데도 전체 인쇄 완료로 표시하지 않도록 결과 안내를 함께 보완합니다.

### 대량 작업의 응답성과 취소

현재는 매수 창에서 전송 전 취소할 수 있지만 전송 중 중단 기능은 없습니다. 대량 전송 중에도 화면이 응답하도록 개선하고, 중단은 아직 보내지 않은 명령을 멈추는 범위로 표시합니다. 이미 프린터가 받은 명령이나 출력한 용지는 프로그램 취소로 되돌릴 수 없습니다.

| 확인 지점 | 승인 후 기준 |
| --- | --- |
| 입력·큐·출력 | 1 / 100 / 101 / 1,000 / 1,001 / 10,000 매수가 끝까지 동일 |
| 생성 방식 | 상품 행당 명령에 매수 기록. 매수마다 같은 이미지를 중복 생성하지 않음 |
| 실패·재시도 | 부분 전송·수신 불명확 상태를 구분. 대량 작업을 자동 재전송해 중복시키지 않음 |

프린터 모델이 받아들이는 명령 수량 범위는 공식 명세와 실제 장비로 확인해야 합니다. 확인된 장비 범위가 필요하면 작업 분할 또는 명확한 오류 안내를 적용합니다. 소프트웨어의 임의 상한 제거가 모든 장비의 무제한 인쇄를 보장하는 것은 아닙니다.

## 승인 후 작업·검증·배포 계획

완료 조건과 이번 검토의 확인 범위

### 진행 순서

① 개체 복사·붙여넣기 구현과 회귀 검증 → ② 인쇄 매수 전체 경로 통일 → ③ 공통 용지 규격 적용과 기존 도안 보호 → ④ 도구 아이콘 복구와 화면 확인 → ⑤ 매뉴얼·빌드·고객배포 파일 동기화 및 통합 검증

| 영역 | 승인 후 완료 조건 |
| --- | --- |
| 개체 | 단일·다중·그룹·이미지·DB 연결 복사, 원본 유지, 반복 붙여넣기, 실행취소·다시실행, 입력란 기본 복사 동작 |
| 아이콘 | 8개 아이콘과 한국어 이름 표시. 배율 100/125/150%에서 문구·클릭 영역 확인 |
| 용지 | 저장 후 재시작 없이 규격·캔버스·명령 치수 일치. 기존 개체·원본 파일 유지. 다른 규격 도안 및 설정 취소 확인 |
| 매수 | 1/100/101/1000/1001/10000 경계 검증. 0·음수·소수 거절. 총매수·취소·부분 실패·재시도 상태 검증 |
| 통합 배포 | 저장소에 정의된 검사·단위/통합 테스트·전체 EXE 빌드. 세 프로그램 실행 확인. 실행파일 해시 일치와 고객 데이터 보존 |
| 매뉴얼 | 단축키·도구 그림·용지 설정 흐름·매수 문구와 화면을 PDF·Word·빠른 안내에 반영 |

이번에 수행한 것은 소스 정적 검토, 이전 시안·배포 캡처 비교, 보고서 PDF 렌더링 확인입니다. 프로그램 테스트·새 빌드·배포·GitHub 갱신·프린터 전송은 하지 않았습니다. 승인 후 실제 장비에서는 우선 1장으로 규격·스캔을 확인하고, 대량 매수와 장비 중단·재개는 모델별로 검증합니다.
