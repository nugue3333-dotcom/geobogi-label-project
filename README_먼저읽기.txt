   IP/포트, Windows 프린터 이름, 용지 유형, 간격, DPI가 맞지 않으면 저장 전에 안내가 표시됩니다.

[2D 바코드 크기 우선 개정 2026.10.13.01]
1. 2D 개체를 더블클릭하여 2D 크기·문자 배치에서 크기 방식을 확인합니다.
2. 새 2D 개체는 바코드 크기 우선으로 시작합니다. 기존 도안은 기존 배치를 유지하며 이 창에서 직접 전환합니다.
3. 바코드 한 변(mm) 또는 바코드 가로(mm)·바코드 세로(mm)는 표시문자를 제외하고 필수 여백을 포함한 코드 영역의 목표입니다. 실제 크기 확인에서 현재 데이터와 출력 DPI 기준 실제 mm·모듈 도트를 확인합니다.
4. 모듈 크기 고정은 고급 방식입니다. 도트 기준과 mm 목표를 동시에 독립 편집하지 않습니다. 데이터 길이나 코드 버전이 달라지면 전체 크기를 다시 확인합니다.
5. 문자 위치는 오른쪽 또는 아래, 문자 간격(mm)은 필수 여백 바깥 간격입니다. 문자 크기는 자동 맞춤 또는 지정 크기를 선택합니다. 문자를 바꾸어도 확정한 코드 크기를 축소하지 않습니다.
6. 개체 전체 가로·세로는 바코드와 표시문자에서 계산합니다. 문자 공간 오류 중에도 손잡이로 조절하며 현재 라벨에 맞추기 또는 문자 아래 배치를 검토합니다. 값 잘림이나 자동 코드 축소로 해결하지 않습니다.
7. 전체 데이터 검증과 인쇄파일에서 크기·라벨 경계를 확인합니다. 목표 mm는 모든 용도의 승인값이 아닙니다. 실제 프린터·스캐너로 한 항목·1매를 확인합니다. 1D의 기존 배치는 유지합니다.

[AI·UDI와 바코드 속성 편집 2026.10.13.02]
1. 바코드를 더블클릭하여 바코드 속성 창을 엽니다. 데이터 원본과 바코드 종류·크기와 표시문자에서 일반 바코드 작업을 합니다. GS1·UDI는 데이터 원본 > GS1 데이터로 설정… 또는 기타 데이터 옵션… > 의료기기 UDI에서 필요할 때만 엽니다. 원본별 입력 초안은 전환해도 보존됩니다. 편집창 하단의 적용 또는 확인으로 저장합니다. 취소·Esc·창 닫기는 마지막 적용값을 보존합니다.
2. 시험용 완성 예제로 시작은 시험용 값입니다. 적용 후 실제 발급·관리하는 번호 또는 DB 열로 바꿉니다. 필수 AI 선택은 부족한 조합을 함께 보여 주며 실제 번호를 임의 생성하지 않습니다. AI21에는 해당 제품의 식별번호가 필요하고 AI37에는 00 및 02/8026 조합을 확인합니다.
3. 새 AI와 수정 중인 행은 검증·적용 전에 자동 반영합니다. 한 AI의 값 칸에는 값만 넣고, (01) 등을 포함한 전체 문자열은 전체 GS1 데이터 가져오기를 사용합니다. 가져오기 미리보기에서 선행 0·항목·값을 확인합니다.
4. 의료기기 UDI는 GS1과 HIBC를 구분합니다. 제품 식별번호(DI)와 로트·일련번호·제조일·사용기한(PI)을 입력하고 고정값 또는 DB 열을 연결합니다. 국내 프로필은 기관 등록·규제 승인 완료를 뜻하지 않습니다. Basic UDI-DI는 GTIN과 다른 정보입니다.
5. HIBC의 원본으로 생성과 완성 코드 가져오기를 구분합니다. 완성 코드는 +접두와 전체 체크문자를 포함한 원문을 입력합니다. 중복 접두·체크문자를 추가하지 않으며 표시문자도 확정한 코드 데이터와 대조합니다. 공백 체크문자는 임의로 제거하지 않습니다.
6. 선택 기호가 긴 UDI를 담지 못하면 값을 보존한 채 GS1 DataMatrix 전환을 검토합니다. 오류 해결을 위해 필수 필드를 삭제하거나 값을 잘라내지 않습니다. 선택 기호별 생성 검증 후 출력 확인과 전체 데이터 검증을 실행합니다.
7. 정사각형은 바코드 한 변(mm), 직사각형은 원래 비율로 조절합니다. 파란 손잡이의 가로·세로·대각선 드래그로 크기를 바꾸고 목표 mm·실제 mm·모듈 도트를 확인합니다. 정수 도트 때문에 작은 이동은 실제 크기가 같은 단계에 머물 수 있습니다.
8. 문자 공간·라벨 경계 오류 중에도 코드 크기 조절·이동·실행취소를 사용합니다. 현재 라벨에 맞추기와 문자 아래 배치를 검토한 뒤 다시 확인합니다. 전체 가로·세로는 코드와 표시문자에서 계산하므로 따로 입력하지 않습니다. 모듈 크기 고정은 도트 변경으로 조절하며 손잡이 조절은 잠깁니다.
9. 해결되지 않은 값·용량·문자 공간·라벨 경계·DB 행 오류는 인쇄를 차단합니다. 저장·재열기·반복 출력의 확정 데이터와 크기를 확인하고 실제 프린터·스캐너에서 한 항목·1매를 검증합니다.

바코드 속성은 데이터 원본부터 열립니다. 직접 입력 / DB·엑셀 연결을 선택합니다. GS1 데이터로 설정…은 첫 화면에서 바로 열고 UDI는 기타 데이터 옵션…에서 선택합니다. 바코드 종류·크기와 표시문자는 별도 메뉴입니다. 상단 미리보기 버튼을 눌러 DB 행, 실제 인코딩 값, 표시문자, DPI와 mm를 확인합니다. 100%와 확대 보기를 사용할 수 있습니다. 오류는 이미지 밖에 표시되며 해결 전 적용은 차단됩니다.
